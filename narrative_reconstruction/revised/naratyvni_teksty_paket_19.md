#### 🌸 ФІНАЛ А: «Перлина Прощення» (Канонічне душевне зцілення)
* **Умова:** перлину піднесено Милані; `FLAG_P19_Q03_DONE` не активний.
* **Дія:** Гравець підносить Милані Перлину Прощення. Дівчина торкається її — ніжка миттєво зцілюється, а перлина в її долоні тане сяйвом. Одна мала перлинка лишається в руці героя як оберіг. Милана залишається жити серед людей і стає нареченою молодого шляхетного воїна.
* **Прапорці:** SET `FLAG_P19_Q03_DONE` + `FLAG_P19_Q03_PEARL`. CHECK: повтор при активному DONE — «Милана сидить на березі Світязя; перлина світиться в її руці.»; нагород не повторює. CLEAR: — (постійні; взаємовиключні з FLIGHT/GUARDIAN — усі ставляться лише через DONE одного проходження).
* **Нагорода гравцю:**
  - **Реліквія:** «Перлина Світязя» (постійний імунітет до хвороб і отрут).
  - **Подарунок:** Золотий весільний рушник Милани (орієнтовно плюс двадцять п'ять відсотків захисту дому — приклад).
  - **Срібняки:** орієнтовно 350 срібняків (приклад).
  - **Титул:** «Рятівник Кривенької Качечки».
* **Наслідок:** Милана ходить — весілля гуде; перлина світиться, доки прощення щире.

#### 🪶 ФІНАЛ Б: «Вільний Вирій» (Поетичний фінал свободи)
* **Умова:** зібрано срібне пір'я [0/7] під нічним ключем і зшито крило ниткою Векли; `FLAG_P19_Q03_DONE` не активний.
* **Дія:** Гравець допомагає Милані зібрати срібні пір'їнки. Вона зшиває крило, прощає старих і залишає їм чарівний рушник достатку, після чого злітає в небо.
* **Прапорці:** SET `FLAG_P19_Q03_DONE` + `FLAG_P19_Q03_FLIGHT`. CHECK: повтор — «Птахи летять над озером; крило вже зшите.» без повторних нагород. CLEAR: — (постійний; взаємовиключний із PEARL/GUARDIAN).
* **Нагорода гравцю:**

  - **Репутація:** орієнтовно плюс сорок п'ять (приклад) (вільні птахи лісу); благословення.
  - **Титул:** «Друг Пташиного Роду».

#### 🌊 ВІДЛУННЯ: «Берегиня Шацьких Вод» (Міфологічний статус)
* **Умова:** обраний третій шлях — Перлину віддано самому озеру; `FLAG_P19_Q03_DONE` не активний.
* **Відлуння:** Перлину віддано озеру — Милана приймає варту берегині.

* **Прапорці:** SET `FLAG_P19_Q03_DONE` + `FLAG_P19_Q03_GUARDIAN`. CHECK: повтор — «Рибалки виходять на воду; озера тихі.» без повторних нагород. CLEAR: — (постійний; взаємовиключний із PEARL/FLIGHT; ставиться разом із DONE).

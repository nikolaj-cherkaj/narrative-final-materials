## 2. NALIVAYKO: отдельная проверка

- P31:747: «встановлюється рівно один, один раз на проходження, permanent; повторного вибору немає».
- `FLAG_REGISTRY.md:3244–3260`: HERO/LAST_STAND/SHADOW — один из трёх; LAST_STAND терминальный; P01 использует только HERO/SHADOW.
- P01:1072–1076: Гаврило реагирует на HERO и SHADOW; для LAST_STAND стоит TECH-примечание о терминальности.
- **Вывод:** one-shot permanent и межпакетное чтение согласованы; новых CHECK нет.

## 3. Ветви и состояния

- P35 Q01: A/B/C взаимоисключающие; B требует шестой смолоскип; C требует 5 пирогов.
- P35 Q04: до крипты общий путь; после крипты выбор варта/спуск; при варте A/B недоступны; при спуске A/B исключают друг друга.
- P36 CRAFT-01: A/B/C после полёта; B — после аварийного приводнения; C — после успешного полёта и копии Кошу.
- P36 CRAFT-02: A/B/C — выбор рейду; C не задевает галеры; пакет безусловный.
- P33: A/B/C явный выбор; ROSA/GRIMOIRE exclusive; мята/пепел имеют источники.
- P20 DAILY-02: A без знака/ниши; B знак; C ниша; действия помечены «только для Б/В».
- P23 GOD-03: A — удержать щит до зенита; B — амулет; C — табуны; условие A в тексте финала сформулировано как «первый луч» (F-07).
- P23 GOD-05: три вопроса — общий гейт; дар в финале; A/B/C соответствуют обещанным дарам; повторного вручения нет.

## 4. SET без CHECK / CHECK без SET

Проверены затронутые группы. Новых «висячих» флагов не обнаружено. Все новые/изменённые состояния имеют потребителя в повторной реплике, финале или P01/P24. `FLAG_P31_Q01_SPOKUTA`/`LITOPYS` читаются в повторных репликах; `FLAG_P35_Q04_SOM`/`RESONANCE` — в повторах; `FLAG_P36_*` — в повторах; `FLAG_P20_DAILY02_LIFELINE` — в описании заряда.

## 5. Вывод

Флаги и развилки в целом согласованы. Остаточные вопросы:

- **F-06:** финал Б P31 Q01 не кодирует, посажен ли уж; это не флаг, а пропущенное состояние в тексте.
- **F-07:** условие финала А P23 GOD-03 не совпадает с формулировкой развилки.
- **R-01:** дымовые горшки P09 Q03 не флаг, но branch-specific предмет.
- Новые ID/флаги не создавались; реестр синхронизирован по формулировкам NALIVAYKO и P35 Q04.

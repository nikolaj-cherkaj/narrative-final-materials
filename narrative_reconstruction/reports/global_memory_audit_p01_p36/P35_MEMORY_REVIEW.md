## 2. Чи є реальне сюжетне значення

Так, часткове: кожен Наслідок описує розв'язку (стіл накрито, міст узято, сом переможений, дзвони налаштовано) і видає конкретні нагороди/титули/перки (Ріг, Палиця, Батіг, Маска, Гніздечко, Спів Щедрика, Клинок, Рушник, Пергамент, Гарпун, Луна). Це чесні результати квестів. АЛЕ системні обіцянки («сонце повертається», «ватра горить», «весна летить», «Бакота говорить», «каньйон гуде», «холод відступає», «погань відступає») не мають персистентної симуляції: погоди, сезону, економіки, звуку світу. Персистентність = DONE + один флаг + заборона повтору. Тобто значення є на рівні нагород, нема — на рівні заявлених змін світу.

## 3. Чи дублюють репліки

Так, усі 8 повторних конструкцій (4 тригери + 4 повтори) семантично дублюють подяки NPC з Акта I/III (Сидорів «Ой, упала коза…», Климентіїв закон Маланки, Златин спів, Антоніїв акорд). Жодна не є дослівною цитатою NPC — це переказ голосом зони, але інформаційно тотожний: «квест пройдено, NPC дякує». Дубль без доданої вартості.

## 4. Чи пояснюють наслідки

Наслідки фіналів — так, побутово («стіл накрито», «міст узято», «сом переможений»). Тригери/повтори — ні: не вказують, який саме фінал обрано (жито/марище/стіл; міст/крило/ватра; ластівка/кристал/рушник; літопис/гарпун/луна). Гравець, що повернувся, отримує лише «село співає» замість «ти обрав X, тому маєш Y».

## 5. Чи приховують відсутність механіки

Так, частково, у 5 місцях:
- M35-03 «сонце повертається» — сезон/погода не змінюються системно; лише артефакт Рога з радіусом.
- M35-10 «Ватра горить» — вічного вогню на майдані як об'єкта нема; лише перк Маски.
- M35-13 «весна летить» — глобальна заява при локальному бафі.
- M35-18 «Бакота говорить» — озвучки каньйону нема; лут + карта.
- M35-20 «каньйон гуде» — постійного гулу/відлякування нема; лише перк Луни.
Це не відсутність геймплею (квести повноцінні), а відсутність заявленої персистентності. Художня фраза маскує разовість ефекту під сталість світу. Оцінка: не критичний дефект механіки, але недобросовісна риторика.

## 6. Два різні дефекти — розведено

1. Погане/однотипне повідомлення: ТАК — 8 повторних конструкцій однотипні з рештою корпусу (зона + «пам'ятає») і дублюють NPC.
2. Відсутня механіка/перехід: НІ — квести P35 механічно повні (етапи, провали, відмови, нагороди, прапорці). Відсутня лише персистентна симуляція світу (погода/вогонь/звук), яку текст обіцяє. Красива фраза НЕ ламає механіку, але створює хибне очікування сталості.

## 7. Вердикт по P35

- Залишити (змістовні): усі 11 Наслідків фіналів + відлуння (M35-03/04/05/08/09/10/13/14/15/18/19/20) — з правкою риторики сталості (див. REWRITE_PROPOSALS.md).
- Видалити/згорнути: M35-01/02/06/07/11/12/16/17 (8 повторних) → замінити системним рядком + конкретним станом («ти підняв Козу; Сидір чекає на …» — ні, без вигадок: лише факт проходження + який фінал).
- Перейменувати: 8 прапорців «пам'ять про…» → назви станів («FROST» = «ватажка розсічено», тощо). Технічний флаг не повинен називатися пам'яттю.

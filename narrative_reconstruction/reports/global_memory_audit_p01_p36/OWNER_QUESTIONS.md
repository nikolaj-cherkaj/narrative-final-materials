# ПИТАННЯ ВЛАСНИКУ — не вирішуються за матеріалами

1. Чи потрібні взагалі художні репліки повторного звернення («X пам'ятає Y»), чи достатньо системного «квест пройдено»? (Аудит рекомендує системні рядки; художні — лише зі слідом вибору.)
2. Чи підтверджується персистентність світу P35: чи мають «сонце/ватра/весна/гул/Бакота» існувати як сталі об'єкти/стани після фіналу, чи це разові катсцени? (Відповідь визначить, чи правити текст або дописувати механіку — друге поза межами цієї сесії.)
3. Чи лишати титул «Хранитель Народної Пам'яті» (P14) як мета-назву при скасуванні масових формул пам'яті? Чи не стане він порожнім після чистки?
4. Світова Пам'ять P01 (Гаврило, ~25 реакцій): чи лишати ретранслятор усіх флагів в одній корчмі, чи розносити реакції по локаціях? Чи не забагато кухлів/нагород за пам'ять?
5. Ехо-слава (думи/пісні після кожного фіналу): скоротити до однієї на лінію? Хто вирішує, який фінал «головний» для слави?
6. Ворожі пам'яті (ціна за голову, холодність замку, клятви помсти, туман холодніший): чи підтверджується їхня механічна дія в інших пакетах, чи це текст? (P03-холодність, P12-туман, P17-хан шукає.)
7. Відкладені пам'яті (Марфа-суперниця, міраж покаже страх, Чорна Пані прийде по своє): чи заплановані їхні спрацювання в пізніших пакетах? Якщо ні — зняти обіцянки з тексту.
8. P36: зафіксувати «лише пам'ять без художньої фрази» як стандарт технічних повторів для всього корпусу? (Аудит — так.)
9. Чи перейменовувати прапорці «пам'ять про…» у стани (P35 та ін.)? Технічне перейменування торкнеться FLAG_REGISTRY — потрібне рішення власника.
10. Масштаб правок (~120 переписати, ~140 згорнути): чи робити однією хвилею або поетапно (спочатку дублі й P35, потім серії P23/P30, потім CHECK-ядра)?

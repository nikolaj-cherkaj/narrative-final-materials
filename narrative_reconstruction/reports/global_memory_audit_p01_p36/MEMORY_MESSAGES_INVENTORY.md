# ІНВЕНТАРИЗАЦІЯ НАРАТИВНИХ ПОВІДОМЛЕНЬ ПАМ'ЯТІ — P01–P36

Аудит: GLOBAL MEMORY MESSAGES AUDIT. Корпус: `narrative_reconstruction/revised/naratyvni_teksty_paket_*.md` (36 файлів).
Схема номерів: AUD-T-xxx — цитовані формули повторів (тригери/CHECK у лапках); AUD-C-xxx — нецитовані CHECK-ядра «X пам'ятає…»;
AUD-N-xxx — рядки «Наслідок» із фіксацією пам'яті/сліду; AUD-S-xxx — змістовні TTS/реакції світу/міжпакетні впізнавання.
Ігрові ID не створювались. Технічні SET/FLAG/CHECK/CLEAR без художньої фрази — не повідомлення пам'яті й номерів не мають.

## ПІДСУМОК КІЛЬКОСТІ

- Група T (унікальні цитовані формули): 91; вживань у тригерах/CHECK: 106.
- Група C (нецитовані CHECK-ядра): 130.
- Група N (Наслідки з пам'яттю): ~60 (див. перелік; частина Наслідків продубльована в S як змістовні).
- Група S (змістовні TTS/реакції/впізнавання/зміни місця): ~150 облікованих проявів, згрупованих за пакетами нижче.
- P36 за строгим критерієм «пам'ятає/слід/пісня/слава природи» — формул нема; є лише технічне «лише пам'ять» і впізнавання-братство (обліковано в S).

## МЕТОДОЛОГІЧНА МЕЖА (що НЕ ввійшло і чому)

1. Інструктивні «Запам'ятай це — а як надумаєш, кажи», «пам'ятай науку/берег/прикмету» — наказ гравцеві запам'ятати механіку, а не фіксація вчинку світом. Виключено.
2. Лорна космогонія («мавка — то пам'ять землі», «мури бережуть пам'ять володарів», «метал має пам'ять і втому» як крафтова властивість) — не про вчинок гравця. Виключено.
3. Плата мосту «пам'ять про найдорожче», «без частки пам'яті» як ціна/шкода — механіка втрати, а не повідомлення про запам'ятовування вчинку. Виключено.
4. Спогади NPC про власне минуле до героя («знав Іларіона замолоду», «пам'ятаю цей Плач ще з уст дідів») — не фіксація дій гравця. Виключено.
5. Чисті технічні рядки «SET FLAG…», «CHECK…», «CLEAR…» без художньої фрази — інфраструктура прапорців. Виключено.
6. Акустичні «відлуння» як саунд-дизайн (відлуння кроків/дзвонів у печерах) без зв'язку з вчинком — не повідомлення пам'яті. Виключено.
7. Загрози стирання пам'яті («туман зітре пам'ять варті») — сюжетна загроза, а не фіксація. Виключено.

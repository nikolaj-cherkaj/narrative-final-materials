# GLOBAL MEMORY AUDIT — P01–P36. ЗАГАЛЬНИЙ ПІДСУМОК

## Масштаб проблеми — підтверджено, але диференційовано

Побоювання власника підтвердилося частково: масовий однотипний шаблон існує (221 унікальна формула «X пам'ятає Y» у 236 вживаннях + 15 дослівних дублів тригер↔CHECK + десятки «впізнає»-замінників), але він покриває НЕ весь корпус. P01–P08 побудовані інакше (Світова Пам'ять, Наслідки-ехо, пряма мова NPC) і містять еталонні зразки. Проблема сконцентрована в P09–P36, пік — P15–P30.

## Скільки знайдено

- Рядків із лексикою пам'яті у 36 файлах: 916 (скрипт-статистика; із них ~половина — інструктивні/лорні/технічні, відсіяні).
- Обліковано повідомлень пам'яті: ~360–380.
  - Група T (цитовані формули): 91 унікальна, 106 вживань.
  - Група C (нецитовані CHECK-ядра): 130.
  - Група S (змістовні TTS/реакції/впізнавання/зміни місця): ~150+ проявів.
  - Група N (Наслідки з пам'яттю): ~26 окремих + решта в S.
- P36: формул за строгим критерієм — 0 (лише технічна пам'ять і впізнавання).

## Скільки змістовні / однотипні / надлишкові

- Дійсно змістовні: ~200 (~55%).
- Частково (текстова слава без механіки): ~70 (~20%).
- Порожні/надлишкові: ~90–100 (~25%) — ядро для чистки.
- Однотипні конструкції: групи T + C повністю (221 формула) + «впізнає»-серії + ехо-слава на кожен фінал.
- Рекомендація: переписати ~120 / згорнути до системного ~140 / лишити ~110.

## Головні повторювані конструкції

1. `[місце/об'єкт] пам'ятає [твою/твій + дія/предмет]` — 91 формула (деталі — REPETITIVE_PATTERNS.md).
2. `CHECK: повтор — X пам'ятає Y; без повторного Z` — 130 ядер.
3. Тригер↔CHECK дослівні дублі — 15.
4. `X впізнає Y` — десятки (P21–P36).
5. `кобзарі складають думу / слава летить / перекази розходяться` — на кожен фінал.
6. `прапорці пам'ятають / пам'ять про…` — технічний флаг як жива істота (P35 та ін.).
7. P35: «зона говорить замість NPC» + риторика сталості без симуляції.

## П'ять найбільш невдалих

1. «Ліс пам'ятає твою сопілку» (P30) — дубль «Явір пам'ятає твою сопілку» (P19).
2. Серія «…пам'ятає твою руку» (12 дослівних повторів).
3. Серія P23 (15 тригерів однією матрицею).
4. «прапорці станів пам'ятають вибір» (P35 ×4).
5. «степ чує твій грім!» як окрема художність без симуляції.

## Новий підхід (стисло)

Пам'ять = інформація про стан світу або її нема. 9 напрямів (деталі — NEW_EDITORIAL_STANDARD.md): конкретне наслідок; зміна ставлення; визнання вустами конкретних; слід лише при реальній зміні місця; предмет-протокол; свідчення персонажа; відкладене прямо; лаконічний системний рядок; відсутність повідомлення. 6 заборон (неживий суб'єкт + «пам'ятає»; «твою руку» без суті; флаг як пам'ять; дублі; разове як стале; >2 повідомлень на квест).

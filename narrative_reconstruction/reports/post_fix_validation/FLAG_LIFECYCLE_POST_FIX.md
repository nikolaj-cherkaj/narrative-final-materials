# FLAG LIFECYCLE POST-FIX — реєстр життєвих циклів

База: вихідники на `014c43b`. Повний машинний парсинг усіх прапорців — поза межами ручного аудиту; нижче — ключові цикли + правила виявлення аномалій. Позначення: SET — встановлення, CLEAR — зняття, CHECK — перевірка умови.

## Зауваження

- P06:310 містить escape-дефект `\FLAG_P01_SAVA_DEBT_DEFAULTED\` та усічене `\DEFAULTED\` — ім'я прапорця пошкоджено в одному рядку, але поруч (P06:304,307; P01:559,562) ті самі переходи записані коректно. Логіка не ламається. Винесено як PF-LOW-004.

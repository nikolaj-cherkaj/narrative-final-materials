# OWNER QUESTIONS — вопросы, неразрешимые по источникам

**Блокирующих вопросов — 0.** Все 8 дефектов устранены в рамках утверждённого канона без новых сюжетных фактов.
Ниже — только необязательные уточнения (ответ не требуется для GO; зафиксированы для отдельной сессии).

## 1. Прямая сдача обладунка Саві (P01:585) — оставить как есть?

Факты: `paket_1.md:585` (сцена P01:580–585) при принесении обладунка ставит только `FLAG_P01_SAVA_DEBT_PAID`
(без `FLAG_P06_DEBT_PAID_ARMOR`, чей SET существует только в P06:311/317). Следствие: D-015 даёт нейтральную реплику
`:1102–1103` «закрив борг» — правдивую, но менее специфичную, чем `:1105` «віддав обладунок».
Варианты: (а) оставить (нейтральная реплика не лжёт; ID с префиксом P06 в сцене P01 — нежелательный прецедент);
(б) добавить ARMOR в P01:585 для симметрии. Рекомендация аудита: оставить (а) — менять нечего, вопрос закрыт наблюдением.

## 2. Орфография «мічений/Мічений» (P23:1095/1097) — унифицировать?

Факты: `:1095` — «Що ж, мічений, доведи…»; `:1097` — «Мічений… Я пам'ятаю…». Одно обращение в соседних строках
написано по-разному. Вопрос: какая форма канонична для стиля Марены? Уровень LOW, на GO не влияет.

## 3. GOD-07: загейтить ли безусловные строки 665/674 под sealed-ветку?

Факты: при активном SEALED игрок слышит сначала безусловное `:665` («Недоля тягне клоччя») / `:674` («прядуть разом»),
затем корректирующие `:667/:675` и памятку `:716`. Семантика закрыта (каст/триггер explicit). Вопрос вкуса:
оставить наслоение (мифологический зачин + уточнение) или добавить условные варианты строк. LOW, не блокер.

## Сводка жизненных циклов

### SET без CHECK

- `Q02_FOREST` (P16) — SET есть, CHECK только в той же строке; сетап отсутствует (`GA-P16-001`).
- `Q03_WARDENS` (P16) — SET/CHECK в одной строке; сетап отсутствует (`GA-P16-002`).
- `Q03_GUARDIAN` (P19) — SET/CHECK в одной строке; выбора нет (`GA-P19-001`).
- `DAILY01_CAPTIVE` (P20) — SET/CHECK в одной строке; сценария памяти нет.
- `DAILY02_LIFELINE` (P20) — SET/CHECK в одной строке; модель расхода не определена (`GA-P20-005`).
- `WEEKLY02_HELMSMAN` (P20) — SET/CHECK в одной строке; отдельного потребителя нет.
- `SMITH_MASTER` / `COURIER_GOLD` (P20) — SET/CHECK в одной строке; отдельного сценария нет.

### CHECK без SET

Не найдено. Все проверяемые флаги имеют SET в тексте или во внешнем пакете (P01 для `TALES19_*`; P24 для `ASHES` — CHECK отсутствует, наоборот).

### Временные флаги без CLEAR

Не найдено: P20 daily/weekly DONE имеют CLEAR по времени; P15–P19 DONE — one-shot, не временные.

### CLEAR, стирающие постоянное состояние

Не найдено: P20 CLEAR применяется только к periodic DONE; `TAMED`, `STREAK_7`, `CAPTIVE`, `LIFELINE`, `HELMSMAN`, `SMITH_MASTER`, `COURIER_GOLD` не снимаются.

### Несколько флагов на одно состояние

- P20 daily: `DAILY01_DONE` (periodic) + `CAPTIVE` (memory) — разные роли, не дубль.
- P20 daily 03: `DAILY03_DONE` (periodic) + `STREAK_7` (one-shot) — разные роли.
- P20 weekly 01: `WEEKLY01_DONE` (periodic) + `TAMED` (permanent lock) — разные роли; `TAMED` доминирует.
- P15–P19: DONE + один state — нормальная схема «маркер + память финала».

### Невозможные/недостижимые состояния

- `Q03_WARDENS`/`Q02_FOREST`/`Q03_GUARDIAN` достижимы текстом финала, но не подготовлены выбором (MEDIUM/LOW выше).
- `Q02_PACT`/`Q02_BROTHERHOOD` — достижимы как финальный выбор, но не посеяны (OBS).
- `LIFELINE` — достижим, но модель повторного получения не определена.

### Циклы повторной награды

- P15–P19: DONE блокирует повтор, циклов нет.
- P20 daily/weekly: повторные награды by design (periodic); исключение — `LIFELINE` (риск бесконечного одноразового спасения, `GA-P20-005`).
- P20 radiant: повторные выплаты by design; `SMITH_MASTER`/`COURIER_GOLD` one-shot.

# QUEST STATE MACHINES — P15–P20 (HEAD `8118d56`)

**Обозначения:**
`L` — locked (DONE активен); `A` — available; `I` — in progress (Акт I/II); `F` — fail (retry, флаг не ставится); `R` — refused (вариант 4, флаг не ставится); `FA/FB/FC/FE` — финал А/Б/В/отголосок; `D` — DONE (финальный флаг); `M` — memory-repeat (DONE активен, только реплика).
Для P20: `D_today` — DONE до 06:00; `D_week` — DONE до понедельника 00:00.
Все переходы в `FA/FB/FC/FE` ставят **ровно один** `*_DONE` + один state-флаг; финалы внутри квеста взаимоисключающие.

## Сложные цепочки

1. **P15 Q01 → Q03:** если Q03 пройден раньше, Q01 Final C (P15:133) читает `Q03_DONE` и Вуж узнаёт героя; обратный порядок — Q03:314 читает `SERPENT_JUDGE`. Оба перехода корректны, но ни один не требует времени года.
2. **P16 Q01 → Q02 → Q03:** независимые DONE; Q02 не требует Q01, Q03 не требует Q02. Никаких блокировок между ними нет.
3. **P18 Q02 ASHES → P24:** P18 заканчивается живой Мамуной; P24 должен прочитать `FLAG_P18_Q02_ASHES`, но не делает этого — внешний долг.
4. **P19 Q01 → P01 D-015:** финал А ставит `TALES19_TELESYK_SAVED` + `GOSLING`; B/C — только `TELESYK_SAVED`; P01:1056–1059 корректно различает.
5. **P20 DAILY-20-03 streak:** `0 → 1 → … → 7`; пропуск → 0; 7-й любой финал → `STREAK_7`; после вручения прапора флаг не снимается, новый стрик с 0.
6. **P20 WEEKLY-20-01 TAMED:** после финала В `TAMED` постоянный; триггер P20:367 блокирует квест навсегда; `WEEKLY01_DONE` продолжает периодически сбрасываться, но не открывает квест.

## Допущения

- Модели времени в материалах нет; `06:00`/`понедельник 00:00` — текстовые правила, не проверенные движком.
- «7 дней» в P16 Q03 — единственный локальный таймер; движок его не подтверждает.
- Все числа наград — примеры; state machine не зависит от их величины.

# КАРТА ФЛАГІВ І СТАНІВ P06–P10 — «Дике Поле»

Джерело істини: `canon/FLAG_REGISTRY.md` v1.5 §§6–10. Тут — робоча карта групи: кожен ID перевірено за текстом (SET/CHECK/CLEAR), а не лише за старими звітами. Тип: `one-shot` (постійний доказ), `state` (стан, знімається), `temp` (строковий). Числа — приклади, не баланс.

## Виявлені помилки

- Орфани (CHECK без SET), несовпадання назв, недосяжні гілки, незнімні стани без причини, суперечливі умови: **не виявлено** (перевірено кожен ID за текстом).
- Фарм: закрито DONE + повторними репліками без нагород у всіх квестах.
- `FLAG_P09_` / `FLAG_P10_` у статистиках — скорочення шаблону (`FLAG_P09_*_DONE`), не окремі ID; реальні ID — вище.
- Реєстр v1.5 синхронізовано: усі 60 ID текстів = §§6–10; нових/пропущених ID у цьому циклі немає; версію піднімати не потрібно (зміни пакетів — уточнення без нових ID).

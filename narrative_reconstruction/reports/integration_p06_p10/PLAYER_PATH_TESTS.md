# ТЕСТИ ПРОХОДЖЕННЯ ГРАВЦЯ P06–P10 — сценарії A–E

Умова: лише реально існуючі варіанти/умови з текстів. Числа — приклади, не баланс. Провали (Fail & Retry) і відмови флагів не ставлять; повтори при DONE — лише пам'ять без нагород.

## Сценарій A. Звичайне проходження (без екстремізму)

- **Початковий стан:** борг Саві відсутній або активний `_50`/`_100` без DEFAULTED; шлюб відсутній; втома свіжа; DONE P07–P10 не активні; мак/полин/вода/хліб збираються за Актами II.
- **Шлях:**
  1. P06 SOC-001: пара, вінки власноруч, хліб/мед/вода, обручки Грицька/Тараса, згода → STARTED → клятви → COMPLETED (поклик, бафи TECH).
  2. P06 SURV-001 → на дим/гомін → втома відступає (без FAINTED).
  3. P06 CRAFT-001: попередження (передзвін/іскра/руна) → вчасно до коваля → зламу немає; або злам → уламки → переков REFORGED.
  4. P06 CRAFT-002 (якщо борг): Хома → Варіант 1 (обладунок→квитанція Сави/Миколи) → `PAID`+`PAID_ARMOR`; Гаврило хвалить.
  5. P06 LORE 01–05: ніша/ущелина/склеп/скриня/печера → усі FOUND → D-015 (P01) → 200 срібняків приклад + «Літописець» одноразово.
  6. P07 PROF-001 А (хрест родині) → DONE (реліквія, юшка/нічліг); PROF-002 А (мастило) → DONE; PROF-003 А (панцир) → DONE (Рада біля горна — один виріб).
  7. P07 DUN-001/002: Веремій/Шуліка → зачищення → перстень/пернач одноразово; повтор — лише сіль/прохід.
  8. P08 MAIN-001 А (оповідь про синє полум'я) → SEAL_DONE + грамота → MAIN-002 А (спаління) → DONE; MAIN-003 А (Око) → DONE; MAIN-004 А (утримано) → DONE; MAIN-005 А (розсічення) → DONE.
  9. P09 Q01 В (підміна: тіло+дим+колискова+ладанка+спалення) → DONE+TRICKSTER; Q02 В (щоденник перед радою) → DONE+JUDGED; Q03 А (сироватка) → DONE.
  10. P10 Q01 А, Q02 А, Q03 А (+артіль ARTEL при DONE) → DONE+пам'яті, викуп бранців, стежки, панцир.
- **Зміни стану:** STARTED→COMPLETED; FAINTED не ставиться; LOST→REFORGED (якщо злам); PAID_ARMOR/WORKED_OFF (якщо борг); усі DONE відповідних квестів; PACT/SOLD/BURNED не ставляться.
- **Результат:** усі обов'язкові завдання доступні й завершувані; переходи логічні (грамота→міст; молитва→криниця; хліб/шнури→гай; внесок/тавро→турнір); персонажі пам'ятають (Гаврило, Онисько, Солоха, Тарас, Радомир, Соломія, Остап, Мартин, Дібровник, Семен); гравець розуміє цілі (Акты I–III, лічильники [0/X]); тупиків немає.
- **Проблеми:** не виявлено (INT-L-002 закрито повторюваністю молитви).

## Сценарій B. Агресивний гравець (насильство, конфлікти)

- **Шлях:** SOC-001 → зрада → SOC-002 Б (BETRAYAL+BROKEN, Тінь до прощення); SURV-001 → «продовжую махати» → FAINTED (половина руди, рана, Гурій «Знову ти?» при повторі); CRAFT-002 Варіант 3 → ранок → відмова → DEFAULTED; P07 PROF-002 В (продаж шпигуну, −600 Ватага, ACONITE_SOLD); P08 MAIN-002 В (продаж грамоти, −1000 карма, SOLD); P09 Q01 А (MARA_MARKED, −5000, незнімне), Q02 Б (ASHED, −800, озеро мертве), Q03 Б (BURNED, −5000? −2500, попелище); P10 — турнір без убивств (загибелі немає задумом).
- **Перевірка реакції світу:**
  - Зрада: обручка б'ється, скриня навпіл, Тінь; прощення знімає BETRAYAL (SOC-001 гілка 3) — послідовно.
  - Борг: крамниці/корчма відмовляють у борг до світанку; Хома повертається; DEFAULTED — борг не згорає, Микола — спадкоємець; новий заєм неможливий (модель C).
  - Темні фінали: знаки/тавра/прокляття незнімні або з ціною (MARA, ASHED-озеро, BURNED-попелище, SOLD-друге дно, PACT-мітка/сни); NPC не поводяться «нічого не сталося» (діти плачуть, рибалки клянуть, Мартин проклинає, купці тримають копію).
  - Закриті шляхи не лишаються доступними: без COMPLETED — SOC-002 закритий («спершу складіть союз»); без SEAL — MAIN-002 закритий; без персня — до мавки не йти; без воску/смоли — спалення неможливе.
  - М'які поразки: падіння/зрив/вайп — повернення наступної ночі/ранку/світанку/після грози/повні; загибелі турніру немає; MAIN-004 Б — герой виживає контуженим (розрив кампанії знято).
- **Результат:** наслідки зберігаються (KILLED/пам'яті постійні; ABSENT відсутній у групі, але UPYR коректно читається); гра продовжувана там, де передбачено м'яке ураження.
- **Проблеми:** не виявлено.

## Сценарій C. Репутаційний гравець (довіра фракцій, доручення, без конфліктів)

- **Шлях:** борги закриваються вчасно (PAID без DEFAULTED, менший наріст наступного); шлюб без зради (CONSENT, без Тіні); PROF-002 Б (еліксир гарнізону, +50 карма приклад, «Рятівник»); P08 MAIN-001 Б (коло, +300 селяни приклад), MAIN-002 А (+1500 карма/+500 військо приклади), MAIN-003 Б (рід очищено); P09 Q01 В, Q02 В (+1500 Вільне Козацтво приклад), Q03 А; P10 Q01 В (побратимство), Q02 В (заповідник), Q03 А+ARTEL.
- **Перевірка:**
  - Умови вступу/пороги не змінювались (Дружина/Зуб — поза групою, у P06–P10 порушень немає).
  - Репутація нараховується послідовно; одноразові нагороди не видаються повторно (DONE + повтори без нагород у всіх квестах).
  - Доступні завдання відповідають репутації (резерв Ореста, цех, гарнізон, громада — за фіналами).
  - Попередні рішення не створюють несподіваних протиріч (CONSENT — без Тіні; FREED — Водяник мирний; JUDGED — Данило живий; DELIVERED — суджено).
- **Результат:** прохідний; протиріч немає.
- **Проблеми:** не виявлено.

## Сценарій D. Дослідник альтернатив (необов'язкове, повернення, відкладання, різний порядок)

- **Шлях:** LORE збираються в довільному порядку (усі 5 потрібні лише разом у D-015); PROF/DUN у довільному порядку (незалежні); MAIN-001 Б/В до/після А (сумісні, якщо вистачило маку/часу); MAIN-003/004/005 у вільному порядку (OBS O-001 — допустимо); Q02: спочатку варіанти 2–4 (розвідка), потім варіант 1 (перстень) → вежа → каплиця (тремтіння; не впізнав — наступна служба, здобуте лишається) → скарбниця (два глухі — третє дзвінке); Острів: відкладене повернення бортником (INT-L-001 🔧); турнір: поразка → втішний герць → повтор наступного ранку без повторного внеску (тавро дійсне).
- **Перевірка:**
  - Альтернативні гілки доступні (3 фінали/2+відлуння усюди; відмова відкладає без втрати здобутого).
  - Відкладені завдання не ламаються (ніч/повня/гроза/світанок — цикли; здобуте лишається).
  - Повторні відвідини коректні (упізнавання Гурія/Ониська/Солохи/Тараса/Радомира/Соломії/Остапа/Мартина/Дібровника/Семена; «Печать іще на тобі»; «Перстень ти вже взяв»).
  - Тимчасові стани завершувані (NIGHTSENSE — повня; BOUND — кров невинного; FAINTED — постійна пам'ять без кулдауну, на відміну від D-006).
  - Неможливого порядку не вимагається (без персня — не йти; без воску/смоли — не палити; без хустки — не пірнати; без SEAL — не на міст).
- **Результат:** прохідний.
- **Проблеми:** не виявлено (молитва — повторювана 🔧).

## 2. Отдельные списки

### 2.1. SET без CHECK

- `FLAG_D020_SWORN` — SET P02:1020, CHECK только P04:32; в P03 Q-021/Q-030 не проверяется, хотя текст ссылается на членство. **FAIL/GA-P03-001.**
- `FLAG_D006_REWARDED` — SET/CHECK в P01; вне P01 не проверяется, но это локальная награда, поэтому допустимо.
- `FLAG_ART_001_FOUND` / `FLAG_ART_003_FOUND` — SET/CHECK в P05; вне P05 не проверяются; локальные one-shot, допустимо.
- `FLAG_P01_LORE_REWARDED` — SET/CHECK в P01; P06 не знает имени, но P06 и не выдаёт награду; допустимо, но требует реестра.

### 2.2. CHECK без SET

- Не найдено в проверенном объёме. Все ключевые CHECK имеют SET в P01–P05 или в P06 (для долга/Летописи).
- `FLAG_P01_CHARCOAL_BURNED` проверяется в P02:908, но SET — P01:371; корректно.
- `FLAG_D020_SWORN` CHECK в P04:32 имеет SET P02:1020; корректно, но нет CLEAR.

### 2.3. Временные флаги без CLEAR

- `FLAG_P05_CHUHAYSTER_ABSENT` — CLEAR описан (P05:96, после 3 рассветов). PASS.
- `FLAG_P01_RADOMYR_WAIT` — CLEAR описан (P01:840). PASS.
- `FLAG_MYKHAILO_RUN_01` — CLEAR не описан; после `RUN_DONE` флаг остаётся, но его CHECK в P01:524 требует «не RUN_DONE», поэтому повторная переправа не открывается. Это допустимо, но флаг висит постоянно; можно CLEAR после `RUN_DONE`. **LOW/OBSERVATION.**
- `FLAG_D006_REPENTED` — CLEAR не описан; «с меткой дня» подразумевает обновление, а не снятие. **OBSERVATION/GA-P01-004.**

### 2.4. CLEAR, способные стереть нужное постоянное состояние

- `FLAG_P01_CHARCOAL_BURNED` снимается в P02:908 при Финале Б. Если Фінал Б ошибочно доступен на сожжённой смолярне, это стирает постоянную память о сожжении. **GA-P02-003.**
- `FLAG_D020_SWORN` не снимается при изгнании — обратная проблема: постоянное состояние членства сохраняется после изгнания. **GA-P03-001.**
- `FLAG_Q021_BRAGA_*` взаимно снимаются (P03:470); это корректно для взаимоисключающих финалов.
- `FLAG_KAZYMIR_*` взаимно снимаются (P04:664); корректно.
- `FLAG_P01_ILARION_*` взаимно снимаются; корректно.

### 2.5. Несколько флагов, описывающих одно состояние

- `FLAG_P01_CHARCOAL_DELIVERED` / `BURNED` — два взаимоисключающих состояния одного квеста; допустимо, но требует строгого CLEAR. Сейчас CLEAR есть, кроме P02:912-оговорки.
- `FLAG_P01_PANAS_ESCORT_DONE` / `FAILED` — два состояния; CLEAR есть.
- `FLAG_P01_ILARION_SAVED` / `LOST` — два состояния; CLEAR есть.

- `FLAG_Q021_BRAGA_TRIED` / `ALLIED` / `BRIBED` — три состояния; CLEAR есть.
- `FLAG_D020_ERRAND_1/2/3` — три независимых one-shot, не одно состояние; корректно.

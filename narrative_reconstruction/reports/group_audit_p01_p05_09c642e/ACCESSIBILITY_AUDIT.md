# ACCESSIBILITY AUDIT — P01–P05

**Проверяемый SHA:** `09c642e`
**Режим:** статическая проверка текста и описанных аудио-сигналов. Реального TTS-прогона не было.
**Итог:** критических зависимостей от зрения в обязательном пути не найдено; остаются LOW-проблемы в необязательных действиях. **`ACCESSIBILITY: CONDITIONAL`**, `TTS NOT TESTABLE`.

## 1. Метод

Проверено:

1. Можно ли обнаружить объект/препятствие без зрения.
2. Есть ли направление и расстояние там, где это нужно для навигации.
3. Понятно ли состояние механизма/устройства.
4. Можно ли распознать успех/провал.
5. Можно ли найти выход и продолжить маршрут.
6. Различаются ли источники звука и голоса.
7. Можно ли выполнить QTE/действие без визуальной подсказки.
8. Понятно ли изменение мира после решения.

Не требовалось механически заменять каждое слово «бачити/дивитися», если это художественная речь. Отмечались только реальные игровые зависимости.

## 4. QTE и действия без зрения

- P01 Q-001: окно 1.5 с по клацанью кресала; голосовой дубль; провал не смертелен (P02:436).
- P02 R-001–R-005: звуковые фазы, гонг, шёпот, треск; есть текстовые дубли.
- P02 Q-010: треск ствола + голос «Готовься» + 1.5 с (P02:850).
- P02 D-020: бой/переправа — голосовые сигналы; одна визуальная опция у вартового (LOW).
- P03 Q-021: парирование по свисту замаха (P03:391).
- P03 Q-030: удар по распорке по скрипу (P03:550).
- P04 SIEGE: удары тарана по скрипу цепей (P04:632).
- P04 BOSS-WORLD-01: фазы по гулу/шипению/треску (P04:695–708).
- P05 BEST-002: бой в воде — звук/вир; поражение описано.
- P05 BEST-008: обряд по петухам/звону; поразка — укус.

**Вывод:** обязательные QTE имеют аудио-телеграф. Визуальные опции есть, но они не единственные.

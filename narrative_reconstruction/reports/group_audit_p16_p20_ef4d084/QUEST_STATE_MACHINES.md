# QUEST STATE MACHINES — P16–P20 (HEAD `ef4d084`)

Нотация: `S0 (нет DONE)` → действие → `S1 (DONE+state)`; повтор → память. Провал/отказ: остаются в S0. Daily: CLEAR 06:00 → S0. Weekly: CLEAR понедельник → S0 (кроме TAMED/HELMSMAN — терминальные ответвления).

## P16–P19 (шаблон one-shot; пример P19 Q01)

```
S0: DONE=0
 ├─ Вариант 4 / провал → S0 (флагов нет)
 ├─ Этап 1 п.4 (нож+вода, только Q01) → S0+предметы
 ├─ Этап 3 A → S1A: DONE+GOSLING (+TALES19_SAVED+GOSLING)
 ├─ Этап 3 Б → S1B: DONE+FURNACE (+TALES19_SAVED)
 └─ Этап 3 В → S1C: DONE+KNIGHT (+TALES19_SAVED)
S1*: повтор → память, без наград; CLEAR: — (навсегда)
```

То же для всех 12 сюжетных квестов (states: WELL/MIRROR/OASIS; CALMED/RAID/FOREST; HEIRESS/WARDENS/PEACE; PEACE/GRIMOIRE/WATCH; STORM/FLIGHT/PACT; MIGHT/ARCHIVE/ALTAR; DAWN/BLADE/MERCY; SWANS/ASHES/WARDENS; STEEL/PITCHER/CALM; GOSLING/FURNACE/KNIGHT; GRYPHON/EGGS/BROTHERHOOD; PEARL/FLIGHT/GUARDIAN). Взаимоисключение: все states ставятся только вместе с DONE одного прохождения.

## DAILY-20-01

```
S0 (DONE=0)
 ├─ отказ/провал → S0
 ├─ этап 3 A (тихо, без полона/сигнала) → S1: DONE
 ├─ этап 3 Б (живец, без сигнала) → S1: DONE+CAPTIVE
 └─ этап 3 В (сигнал+сотня+12) → S1: DONE
S1: повтор сегодня → память; CLEAR 06:00 → S0
```

## DAILY-20-02 (+ LIFELINE)

```
S0 (DONE=0, заряд L=z)
 ├─ отказ/провал → S0 (z без изменений)
 ├─ этап 3 A (без знака/ниши) → S1: DONE (z без изменений; Нитка не выдаётся)
 ├─ этап 3 Б (знак; нишу не открывать) → S1: DONE+LIFELINE, z:=1 (замена)
 └─ этап 3 В (ниша вместо знака) → S1: DONE (z без изменений)
Смерть со знаком: z=1 → спасение, z:=0 («гасне»)
Следующий Б: z:=1. Повтор Б в тот же день: блокирован DONE.
```

## DAILY-20-03 (+ стрик)

```
Счётчик c=[0..6], STREAK_7 ∈ {0,1}
S0 дня (DONE=0)
 ├─ отказ/провал → пропуск: c:=0 (если был стрик-день) / без изменений DONE
 ├─ дни 1–6: A → DONE, c+1; Б → DONE, c+1
 └─ день 7 (c=6): только В (путём А или Б): DONE, c=7→STREAK_7:=1, титул
   А/Б на 7-й день отдельно не оформляются.
```

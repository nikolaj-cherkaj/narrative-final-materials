- CLEAR, стирающий нужное: нет (CLEAR только daily/weekly DONE по времени; стрик сбрасывается только пропуском).
- Дубли одного состояния: нет (state-флаги взаимоисключающие).

- Циклы повторной награды: нет («лише один набір» + DONE + одноразовые майлстоуны).

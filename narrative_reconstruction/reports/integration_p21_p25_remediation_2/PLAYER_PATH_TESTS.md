## 1. PACT / BURNED / без флагов — P24 DARK-24-01

### 1.1. Путь PACT

1. P09 QUEST-03, финал-пакт: игрок открывает проход в лагерь обложников → `FLAG_P09_Q03_DONE` + `PACT`.
2. P24 DARK-24-01, Акт I: звучит голос Моровицы «Ти? Я пам'ятаю твою мітку… Віддай борг…».
3. Игрок проводит обряд; выбирает A/B/C.
4. В любом финале Моровица отступает, не гибнет; метка/долг остаются; `PACT` не снимается.
5. Повторный вход: «Мітка на тобі, козаче. Борг не згас — я чекаю».

**Ожидание:** PACT-реакция слышна до финала и при повторе; награды не дублируются.
**Фактически:** P24:28–41, 76–90, 132–151. PASS.

### 1.2. Путь BURNED

1. P09 QUEST-03, финал Б: игрок поджигает форпост → `FLAG_P09_Q03_DONE` + `BURNED`.
2. P24 DARK-24-01, Акт I: вместо живой Моровицы — столб пепла, шелест «...село... тепло...», без голоса/памяти/долга.
3. Игрок проводит обряд; A/B/C работают с пеплом: A — пепел развеивается, B — притиснут железом, C — запечатан вапном.
4. Метки/долга нет; PACT-реплик нет.
5. Повтор: «Попіл Моровиці більше не встає».

**Ожидание:** Моровица не изображена живой.
**Фактически:** P24:28–41, 84–90, 108, 132–151. PASS.

### 1.3. Путь без PACT/BURNED

1. P09 QUEST-03, финал А (или квест не пройден) → нет PACT/BURNED.
2. P24 DARK-24-01: обычная враждебная пошесть; финалы A/B/C без PACT/BURNED-реплик.
3. Повтор: «Борозна пам'ятає твій крок».

**Ожидание:** сцена не ломается, нет упоминания пакта.
**Фактически:** P24:28–41, 132–151. PASS.

### 1.4. Аномалия PACT + BURNED

1. В сохранении оба флага (недостижимо нормальной игрой).
2. P24 отдаёт приоритет BURNED; PACT-сцены имеют условие «и не BURNED»; живая Моровица не показывается.

**Фактически:** P24:33, 76, 132–151. PASS.

4. Попытка выбрать B/C до Крока 3: Устим останавливает («Спочатку вода, потім лава»).

### 4.5. Провал/отказ

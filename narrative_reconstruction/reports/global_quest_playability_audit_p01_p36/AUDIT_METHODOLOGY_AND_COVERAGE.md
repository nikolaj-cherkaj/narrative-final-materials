## 3. Критерии статусов (применялись строго)

- `CLEAR` — цель, место, исполнитель, глагол, предмет, счётчик, фидбэк и провал/повтор следуют из текста; угадывание не нужно.
- `PARTIAL` — цель ясна, один подэлемент неясен (эпизодический вендор без имени; тара; срок ожидания).
- `UNCLEAR` — метод/завершение допускают несколько прочтений (verb отсутствует или двусмыслен).
- `MISSING` — требуемый элемент вообще не описан (предмет без источника; действие без глагола).
- `BLOCKED` — прохождение невозможно (тупик; отсутствующий обязательный материал/триггер).
- `NOT APPLICABLE` — критерий неприменим (серверные сигналы, read-only реплики памяти).
- Художественное описание ≠ инструкция. TTS/звук не тестировались; звуковые маяки принимались как доступные сигналы (навигация звуком разрешена проектом).

## 4. Нормализация (зафиксированные расхождения групп)

1. **«Линейный Акт II → выбор в розв’язці».** P25–P30 считали выбор в блоке «РОЗВ’ЯЗКА/ВИБІР ШЛЯХУ» достаточным (CLEAR по пункту выбора); P19–P24 требовали ветвления уже в Акте II (HIGH). Решение синтеза: выбор в розв’язці = CLEAR для пункта выбора, **кроме** случаев, когда пути требуют разных подготовительных предметов, не добытых в Акте II (кейс P21-01 казан/бочка — ITEM-GAP, HIGH/CRITICAL). Системные пометки «шлях X з етапу 3» без шага выбора оставлены как MEDIUM-линковка (PD-115/118/127), а не HIGH.
2. **Гранулярность PARTIAL.** P31–P36 ставили PARTIAL за каждый микрошаг с неназванным источником (отсюда 57% PARTIAL); P25–P30 те же случаи считали CLEAR с LOW-замечанием. Итоговые суммы приводятся как заявлено группами; вывод о готовности делается по числу HIGH/CRITICAL, а не по доле PARTIAL.
3. **Эпизодические вендоры** (кузнец, крамар, праля без ID/имени): PARTIAL/LOW, допустимы по §6.2; сгруппированы в один PD/вопрос на пакет.
4. **Баланс** не оценивался; «орієнтовно … (приклад)» — примеры. Проверялась только логика: наличие, условие, одноразовость, соответствие ветви.
5. **Время** («до третіх півнів», «до заходу сонця», yearly Здвиження): движковой модели времени в материалах нет (подтверждено аудитами GA-GROUP-001); трактуется как художественный дедлайн = OBSERVATION, кроме мест, где от него зависит механика (помечены отдельно).

# ПРОБЕЛЫ ВЗАИМОДЕЙСТВИЙ (INTERACTION_GAPS)

Действия, для которых не определён способ взаимодействия (глагол/инструмент/источник/успех).
Формат: цитата | файл:строка | что предлагается | чего не хватает | эффект. Привязка к PD/OQ.

## MEDIUM (массовые; полный список — в PRIORITIZED_DEFECTS)

Типовые: тара/сосуды (куманець, чаша, глечик, бочонки, фляги); second-барьеры; тексты заговоров/молитв для TTS; судьи счёта (поединки, ничьи); порядок заплыв/венок; сроки аренды; свидетели сделок; механика тревоги/ретрая. Каждый — 1 строка PD с файлом:строкой.

## Проверка художественное vs инструкция (примеры не-зачёта)

- «Ледяной вихрь рвётся к окнам» (P35 Акт I) — атмосфера; действия не даёт → MISSING (окна).
- «Коло розімкнулось» (P35 fail) — состояние без определения → не ретрай-механика.
- «Почути… вийти… прийняти…» (финалы P35) — сенсорные условия без offerer — выбор не staged.
- «Тримай стрій, сип зерно знову» — ободрение, не точка/объём повтора.

Итого пробелов: ~115 глагольных + ~100 источниковых (детализация — PRIORITIZED_DEFECTS, ITEM_AND_RESOURCE_FLOW).

# ВЕТВИ И ФИНАЛЫ (FINALE_AND_BRANCH_PLAYABILITY)

Правило проекта: повтор после завершения = реплика именно выбранного финала. Проверено: соблюдается везде, где финалы различаются флагами-состояниями (P13–P36: DONE + B/V-состояния; P01–P12: DONE/память-флаги). Регрессий не найдено.

## 1. Структура финалов по кластерам

- P01–P12: 2–3 финала + отказы/память; эксклюзия через DONE/флаги (BURNED/PACT, KILLED/ABSENT, SWORN-срезы). Условия выбора — жест/реплика/путь (P08/P09/P12 — в диалоге; P10/P11 — роздоріжжя/стрибок).
- P13–P24: 3 финала (A = DONE-only; Б/В = DONE+state, взаимоисключающие) + 6 відлунь (P15-03, P16-03, P17-03, P18-03, P19-03, P23 ×8 echo/secret). Выбор — вузол в Этапе 3 / «РОЗВ’ЯЗКА».
- P25–P30: 3 финала (A DONE-only; Б/В excl.) + echo (KANIV, TRYPIL-C?). Выбор staged («Спочатку вода, потім лава» — образцовый гейт P25-02:219).
- P31–P36: 2–3 финала + echo (A DONE-only; пары excl.: BEACON/PACT, WARDEN/STORM, ROSA/GRIMOIRE, TRIUMPH/LEGACY, FROST/FEAST, STORM/WATCH и т.д.). Подтверждены FIXED: TRAP+GROVE-стек, clever-формулировка, NALIVAYKO-исключение (кроме формулы — PD-153).

## 3. Случайный вход в нежелательную ветвь (риски)

- WITCH B→V-локаут без предупреждения (CRITICAL-риск; PD-175).
- P19-03 echo vs Б: игрок, отдавший Перлину озеру, может не понять, что закрыл Б (счёт перьев всё равно отсутствует — двойной дефект).
- MEADOW A-vs-B: оба условия выполнимы за run; приоритет не задан (PD-174).
- BAKOTA настройка (шаг) vs финал V: вход может пред-решить финал (PD-199).
- P22/P21/P23 линейные Этапы: случайный «не тот путь» невозможен (выбор в розв’язці), но и осознанная подготовка невозможна там, где пути требуют разных предметов (P21 — реальный риск; остальные — только подтверждение модели).

## 4. Повторные обращения (проверка правила)

- P13–P36: у каждого DONE — 2–3 строки памяти по состояниям (проверены все 77+ концовок P31–36; P35 — повторные строки обновлены memory-revision, но pilot-OQ не закрыт, т.к. строки не отвечают на вопросы механики).
- P01–P12: память Гаврилы (D-015) по всем флагам incl. KILLED/ABSENT; UPYR_RESTED; ILARION; PANAS DONE/FAILED; долг PAID/WORKED_OFF/DEFAULTED — все совпадают.
- Нарушений правила (строка чужого финала) — **0**.

# OWNER APPROVAL REQUIRED — питання, що потребують рішення власника

Тільки реальні питання. Уже ухвалені рішення (Зуб, видача, арени, Око, перейменування, fence, сирени, мова, NPC-дубль) не перевідкриваються.

## №1. Модель дефолту боргу Сави (P01/P06) — підтвердити реалізоване

- Проблема: текст обіцяв і «борг не зникає», і новий займ, що знімав `DEFAULTED`.
- Реалізовано: відновлювана модель C — дефолт закривається грошима/обладунком/відробітком через Саву/Миколу/Хому; новий займ при боргу чи дефолті заборонено.
- Варіанти: A — термінальний дефолт (прибрати сцени повернення після дефолту); B — лише гроші після дефолту; C — реалізовано (рекомендація аудиту).
- Питання: підтвердити C, чи обрати A/B?

## №2. Ланцюжок вступу до Світлої Дружини (P02 D-020 / P01 D-006)

- Три доручення без ID/нагород/чисел; покаяння без явних +карма/+репутація.
- Варіанти: A — повноцінна цепочка з числами; B — доручення як фон, числа дає покаяння; C — прибрати доручення.
- Питання: який варіант і які числа?

## №3. Пороги репутації Гільдії Майстрів (P02 D-022)

- Уніфіковано під шкалу: `≥ +500` / `< +500` / висока `≥ +2000` (рекомендація A аудиту).
- Питання: підтвердити числа +500/+2000 чи задати інші в межах −5000…+5000?

## №4. Вплив класу на наратив (P04 `FLAG_P04_CLASS_CHOSEN`)

- Область дії задокументовано (P04 + бойова система).
- Варіанти: A — 2–3 реактивні репліки/доступи; B — клас лише бойовий; C — мінімум (P04 + одна точка в P06).
- Питання: який варіант і де точки?

## №5. Умова повтору P16 QUEST-16-03

- Текст: «Умови повтору — на розгляді геймдизайнера».
- Варіанти: A — одноразовий; B — повтор за часом; C — за ресурсом/дозволом NPC.
- Питання: який варіант (текст заглушки прибрати після рішення)?

## №6. Ставки QUEST-18-01 + суперечність спроб

- Провал грозить спаленням хутора, але loop дозволяє повтор; додатково P18:62 «без обмежень» vs P18:275 «спроб: 3».
- Варіанти: A — термінальний провал; B — м'який (морок проривається, хутір стоїть); C — умовний (хутор гине при повторному провалі). Плюс уніфікувати ліміт спроб.
- Питання: який варіант?

## №7. PROPOSED-сутності (Цар-Вуж, Моровиця, Оксен, Мамуна, Устим)

- Цар-Вуж: P15 (білий, один ріжок, мова природи) vs P28 (чорний, два роги, замки+золото). Канон обрав білий образ, але статус PROPOSED.
- Питання: уніфікувати під білий/один (правити P28) чи розвести на два ID? Підтвердити інші чотири образи.

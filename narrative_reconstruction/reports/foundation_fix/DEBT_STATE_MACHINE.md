# DEBT STATE MACHINE — борг Сави P01/P06 після виправлення

**Проблема:** FF-HIGH-P01-P06-DEBT-001. Реалізовано відновлювану модель (варіант C з OWNER_DECISIONS_GAPS): дефолт закривається грошима/обладунком/відробітком, новий займ старого боргу не списує. Власнику — підтвердити B/C.

## 1. Стани

`NONE` (боргу немає) → `DEBT_100` | `DEBT_50` → `PAID` / `DEFAULTED` → `PAID` (через погашення прострочки). `PAID` і `DEFAULTED` взаємовиключні; `_100` і `_50` взаємовиключні (тепер забезпечено CLEAR в обох вітках видачі).

## 2. Переходи

| Подія | Умова | Перехід | Прапорці |
|---|---|---|---|
| Взяти 100 | `NONE`, немає `DEFAULTED` | `NONE` → `DEBT_100` | SET `_100`; CLEAR `_50/PAID/DEFAULTED` |
| Взяти 50 | `NONE`, немає `DEFAULTED` | `NONE` → `DEBT_50` | SET `_50`; CLEAR `_100/PAID/DEFAULTED` |
| Повернути грошима (D-005) | `_100`/`_50` АБО `DEFAULTED` | → `PAID` | CLEAR боргові+`DEFAULTED`; SET `PAID` |
| Обладунок (D-005 / CRAFT-002 В.1) | `_100`/`_50` АБО `DEFAULTED` | → `PAID` | + `FLAG_P06_DEBT_PAID_ARMOR` |
| Відробіток (CRAFT-002 В.2) | `_100`/`_50` АБО `DEFAULTED` | → `PAID` | + `FLAG_P06_DEBT_WORKED_OFF` |
| Відмова після CRAFT-002 | `_100`/`_50` | → `DEFAULTED` | CLEAR боргові+`PAID`; SET `DEFAULTED`; борг переходить до Миколи |
| Новий займ при боргу/`DEFAULTED` | — | **заборонено** | спершу закрити старий борг |

## 3. Тестові сценарії (усі PASS за текстом)

| # | Дія | Очікувано | Фактично |

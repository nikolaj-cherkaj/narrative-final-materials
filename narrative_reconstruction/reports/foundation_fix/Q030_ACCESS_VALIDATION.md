# Q-030 ACCESS VALIDATION — повна модель доступу після виправлення

**Проблема:** FF-HIGH-P03-Q030-001. Підтверджені рішення власника: Зуб видається при кармі ≤ −500 або репутації Ватаги ≥ +500; обмеження Світлої Дружини (СД) ≥ +2000 має пріоритет; третьої альтернативи немає; альтернативний шлях (бій/хитрість) — лише ціною розриву (репутація < +2000, контракти/знижки закрито до покаяння); зняття герба недостатньо.

## 1. Видача Зуба (P02 D-021) — без змін, перевірено

- Умова: карма ≤ −500 АБО Ватага ≥ +500.
- Обмеження: СД ≥ +2000 → Зуба немає (незалежно від карми/Ватаги).
- Статус: коректно.

## 2. Вхід у Q-030 (P03) — виправлено

| Шлях | Умова входу (після fix) | Статус СД ≥ +2000 |
|---|---|---|
| Із Зубом, СД < +2000 | Зуб діє; Дорош пропускає | — |
| Із Зубом, СД ≥ +2000 | **Зуб недійсний**; як без Зуба при СД ≥ +2000 | розрив або закрито |
| Без Зуба, карма ≤ −500, СД < +2000 | Дорош пропускає | — |
| Без Зуба, СД ≥ +2000 | бій/хитрість із **розривом** (репутація < +2000, контракти/знижки закрито); зняття герба недостатньо; інакше закрито | втрата статусу |

Пріоритет вітки СД ≥ +2000 збережено й поширено на Зуб.

## 3. Тестові сценарії (усі PASS за текстом)

| # | Початковий стан | Дія гравця | Очікувано | Фактично |
|---|---|---|---|---|
| 1 | СД < +2000 → отримано Зуб | підняти СД до +2000, пред'явити Зуб | Зуб не діє; потрібен розрив | відповідає тексту |
| 2 | СД < +2000 → Зуб | підняти СД вище +2000, пред'явити Зуб | Зуб не діє | відповідає тексту |
| 3 | СД ≥ +2000 | просити Зуб у Грицька | відмова | відповідає тексту (P02:1087) |
| 4 | СД ≥ +2000, є старий Зуб | зняти герб, пред'явити Зуб | не діє («знають в обличчя») | відповідає тексту |
| 5 | СД ≥ +2000, є старий Зуб | маскування | не діє (той самий принцип) | відповідає тексту |
| 6 | будь-який + готовність платити | бій | доступ; СД < +2000, контракти/знижки закрито | відповідає тексту |
| 7 | будь-який + готовність платити | хитрість | доступ; та сама ціна | відповідає тексту |
| 8 | після розриву | просити скидки/контракти СД | закрито до покаяння | відповідає тексту |
| 9 | після розриву | покаяння | шлях відновлення (числа — див. питання власнику D-020) | частково; не приховується |
| 10 | СД ≥ +2000 без Зуба | повторне звернення до Дороша | закрито без розриву | відповідає тексту |

## 4. Критерій

Жоден шлях не дозволяє зберегти СД ≥ +2000 і безплатно скористатися доступом: **виконано.**

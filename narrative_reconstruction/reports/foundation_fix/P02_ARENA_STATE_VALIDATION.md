# P02 ARENA STATE VALIDATION — R-001…R-005

**Проблема:** FF-HIGH-P02-ARENA-001. Вхід/запечатування описані; виходу після перемоги не було.

## 1. Загальний ритуал R-001 (Arena Lock)

- Вхід: сходи схід→захід; перший дар → гранітні брили + стіна синього полум'я; голос системи: «Вихід запечатано…».
- **Перемога (fix):** бар'єр падає → завал осідає, між брилами відкривається вузький прохід нагору (тяга повітря, шум лісу, голос вівтаря). Дари витрачено.
- **Поразка:** відродження в місті; дари втрачено; бос зникає до наступного ритуалу. Без змін.

## 2. Схеми перемоги за аренами

| Арена | Вхід | Блокування | Вихід після перемоги (fix) | Орієнтир (аудіо) |
|---|---|---|---|---|
| R-002 Чорнобог | східні сходи | західний завал (старий) + бар'єр | східні сходи вільні; західний завал лишається | тяга повітря, шелест лісу, голос вівтаря |
| R-003 Кощій | південні сходи | сходи завалюються | каміння осідає — вузький прохід сходами нагору (завал прохідний, не зниклий) | тяга згори, дзвін золота позаду |
| R-004 Вій | південний тунель | тунель (бойова зона) | південний тунель вільний, назад навкарачки | свіже повітря, голос вівтаря |
| R-005 Баба-Яга | бічний тунель → галявина → хата (двері зачиняються) | замкнені двері | двері відчиняються самі; галявина → бічний тунель → Капище | каркання круків, скрип ніг, лісове повітря |

## 3. Сценарії

| # | Стан | Очікувано | Фактично |
|---|---|---|---|
| 1 | Перемога в кожній з 4 арен | описаний вихід + скриня | PASS (4/4) |
| 2 | Поразка (wipe) | відродження в місті, дари втрачено | PASS (без змін) |
| 3 | Повторний рейд | можливий після нового набору дарів | PASS (без змін) |
| 4 | R-003: сходи завалено | вихід не через «розчищений» прохід без пояснення, а через осідання завалу | PASS — суперечності з R-003:159 немає |
| 5 | Аудіодоступність | вихід зрозумілий без зору | PASS — усі орієнтири звукові/нюхові |

Просторова логіка не суперечить раніше описаній географії: жоден «завалений назавжди» прохід не використано без пояснення.

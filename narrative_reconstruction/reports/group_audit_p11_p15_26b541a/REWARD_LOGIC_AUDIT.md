# REWARD LOGIC AUDIT — P11–P15 (HEAD `26b541a`)

Без оценки числового баланса; только наличие, условия, одноразовость, непротиворечивость, титулы. Все числа — «(приклад)».

## Наличие и условия — PASS (15/15 квестов)

Каждый финал/відлуння имеет блок нагород: оружие/артефакт/перк/репутация/валюта/досвід + титул. Примеры: P11 Q01 А (клинок/нагрудник/350 червінців/титул `P11:127–131`), P12 Q01 А (благословення/палаш/400 срібняків/титул `P12:147–151`), P14 Q02 А (пернач/400/титул без механики `P14:269–273`), P15 Q03 Б (500 червінців з воза/титул `P15:372–375`).

## Одноразовость — PASS

Все DONE one-shot; повтор — «без повторних нагород/срібняків/досвіду» (см. FLAG_LIFECYCLE_AUDIT). Ключевые реликвии: меч P12 возвращается (`P12:146/161/175`), рог P15 — три разные судьбы без дубля (A — вузлик `P15:358`, Б — Царю `P15:370`, Відлуння — джерело `P15:383`), сопілка P13 — запасные (`P13:238/370`), мольфа P13 — одна на игрока (`P13:92`), Бартка — одна судьба на проход (`P13:275/288/300`), пектораль — не выдаётся игроку (`P14:390/402/415`).

## Провал/отказ — PASS

Провалы и отказы наград не дают (триггеры: «жодного флага НЕ ставлять» + отсутствие нагород в fail-блоках `P11:108/264/403`, `P12:128/258/389`, `P13:131/257/395`, `P14:126/250/373`, `P15:90/217/341`).

## Титулы/достижения — PASS

Титул в каждом финале (напр. «Посвячений Громом», «Оборонець Золотоверхого», «Хмарник Чорногори», «Око Дикого Поля», «Обранець Царя-Вужа»); дубликатов титулов внутри пакета нет; титул отделён от механики там, где нужно (`P14:270–271` «почесне звання; окремих механічних бонусів не створює»).

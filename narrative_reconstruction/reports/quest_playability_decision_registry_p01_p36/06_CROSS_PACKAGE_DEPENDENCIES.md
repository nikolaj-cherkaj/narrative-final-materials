## Наслідки неправильних роздільних рішень
- B02(гейт) без правила інвентаря → плутанина порядку Q01/Q03 (зафіксувати в тригері одним рядком).
- B04 без винятку P21 → «вибір-у-розв'язці» узаконить шляхи без предметів (виняток обов'язковий).
- B06 без X-02 → споживач P01 залишиться на сміттєвій формулі.
- B07 (P35) окремо від D01 → механіка на висячій локації (спочатку D01-перейменування).
- B08 роздільні вендори P32/P36 → розбіжність економік (єдина рамка «бочка з порохом»).

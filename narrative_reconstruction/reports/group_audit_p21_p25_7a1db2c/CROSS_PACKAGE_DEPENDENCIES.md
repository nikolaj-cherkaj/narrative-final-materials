| Параметр | Значение |
|---|---|
| Источник SET | P09 QUEST-03: `PACT` — P09:465; `BURNED` — P09:451–452 |
| Потребитель | P24 DARK-24-01, Моровица NPC-0100 |
| Критерий закрытия | P24 читает `FLAG_P09_Q03_PACT`; при PACT Моровица узнаёт метку и помнит «прийде по своє», метка/долг не исчезают; при `BURNED` P24 не ссылается на живую Моровицу; тесты «пакт / без пакта / BURNED»; повтор не теряет реакцию |
| Фактическое состояние | **`PARTIALLY FIXED` / `NOT CLOSED`** |
| Доказательство | P24:99, 109, 118 — реальные PACT-реплики в финалах A/B/C; PACT не сбрасывается. Но P24:26 проверяет только PACT; `FLAG_P09_Q03_BURNED` в P24 — 0 вхождений; P24:24–26, 99–121 всегда показывают живую Моровицу. | Влияние | После P09 BURNED Моровица снова жива и говорит; PACT-реакция не слышна до финала и исчезает при повторе; реестр `CLOSED` не подтверждён |
| Целевой цикл | P21–P25 (текущий) |
| Рекомендация | Добавить CHECK `BURNED` и ветку «попіл/луна», добавить слышимую PACT-реплику в Akt I и при повторе; синхронизировать §0/§24 и `GLOBAL_CARRYOVER_REGISTER` |

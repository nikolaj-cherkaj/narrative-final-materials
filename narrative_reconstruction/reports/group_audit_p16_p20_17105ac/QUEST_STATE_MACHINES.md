# QUEST STATE MACHINES — P16–P20 (HEAD `17105ac`)

**Обозначения:** `A` — доступен; `I` — в процессе (Акт I/II); `F` — провал (retry, флаг не ставится); `R` — отказ (Вариант 4, флаг не ставится); `D` — DONE; `M` — память при активном DONE; `FA/FB/FC/FE` — финал А/Б/В/отголосок. Для P20: `D_day` — DONE до 06:00; `D_week` — DONE до понедельника 00:00.

**Базовое правило P16–P19:** каждый финал ставит ровно один `*_DONE` + один state-флаг; финалы взаимоисключающие; провал/отказ флагов не ставят. **Для P20 это правило текстом не обеспечено для D1/D2/D3/W2 — см. §3.**

## 3. Детальные машины P20 (дефектные ветвления)

### DAILY-20-01

```
A_day ──> I ──> FA (kill, captain not alive, bunchuk) ──> D_day ──> M
          │
          ├──> FB (captain alive, handed over) ──> D_day + CAPTIVE ──> M
          │
          └──> FC?  (smoke signal, 12 riders)  <-- НЕТ ПЕРЕХОДА ИЗ I
```

- В `I` есть этап 3: 3 всадника, выбор «уничтожить / захватить». Действия «подать сигнал» нет. `FC` описан только в блоке финала (P20:117–118) и в реплике Варианта 2 (P20:46), но не в этапах.
- Следствие: `FC` недостижим; 12 всадников не появляются. `DAILY01_DONE` в реестре говорит «любой финал А/Б/В», но В не reachable.

### DAILY-20-02

```
A_day ──> I ──> FA (7 lamps) ───────────────┐
          │                                ├──> D_day (все три могут сработать)
          ├──> FB (sign at altar) ──────────┤
          │                                │
          └──> FC (niche behind sarcophagus)┘
```

- `FA` условие — 7 лампад (P20:203). `FB` — знак у алтаря (P20:216); алтарь/принятие знака в этапах не описаны. `FC` — ниша за саркофагом (P20:228), обнаруживается при зажигании 7-й лампады (P20:229), т.е. в том же действии, что и `FA`.
- Нет `XOR` и нет state-флага финала. Следствие: один проход может дать A+B+C; награды суммируются.

### DAILY-20-03

```
A_day ──> I ──> FA (all 5 wagons) ──> D_day + streak+1 ──> M
          │                              │
          ├──> FB (camp cleared) ────────┤
          │                              └── 7-й: STREAK_7 + титул (A/B blocks)
          │
          └──> FC (7 caravans in a row) ──> D_day + STREAK_7 + реликвия/опыт/титул
```

- `FC` — не отдельный исход дня, а milestone 7-го каравана. Блоки A/B уже выдают `STREAK_7`+титул на 7-м; блок C добавляет реликвию/опыт. Не сказано, заменяет или дополняет.
- Следствие: неоднозначная награда 7-го каравана.

### WEEKLY-20-02

```
A_week ──> I ──> FA (all boats/cannons intact) ──┐
           │                                     ├──> D_week (A и C совпадают)
           ├──> FB (squadron shot from cannons) ─┤
           │                                     │
           └──> FC (steersman mastery) ──────────┘
```

- `FA` и `FC` — оба истинны при успешном прохождении. `FB` требует пушечного залпа; фаза 3 говорит только «отбитие абордажа». Нет `XOR` и state-флага.
- Следствие: A+C (и возможно B) за один запуск; награды суммируются.

### WEEKLY-20-01 (корректная модель)

```
A_week ──> I ──> (фаза 3) ──> FA (kill → phase 4 tusks) ──> D_week
          │                   │
          │                   ├──> FB (kill → phase 4 skin) ──> D_week
          │                   │
          └───────────────────└──> FC (heal/tame) ──> D_week + TAMED ──> L навсегда
```

- `FA`/`FB` — выбор в фазе 4; `FC` — выбор в фазе 3. `TAMED` блокирует триггер навсегда. Это корректная взаимоисключающая модель; OBS только про «разбитые пластины vs шкура».

## 5. Примечания

1. **P16–P19:** state-флаги финалов обеспечивают взаимоисключение; текст и флаги согласованы. `GA-P19-003` — не состояние, а отсутствующий предмет для FC.
2. **P20 D1/D2/D3/W2:** нет state-флагов финалов A/B (кроме `CAPTIVE`, `LIFELINE`, `TAMED`, `HELMSMAN`, `STREAK_7`), поэтому движок не может отличить финал. Это корень `GA-P20-012`…`015`.
3. **P20 W1:** корректная модель; единственное OBS — `GA-P20-017`.
4. **P20 D2 `LIFELINE`:** заряд — runtime-переменная; флаг — память. Модель варианта B: `charge=1` при B; `charge=0` после срабатывания; `B` снова → `1` (замена); повтор в тот же день — `DONE`.
5. **P20 D3 `STREAK_7`:** счётчик `0..7`; пропуск → 0; 7-й любой финал → `STREAK_7`; после вручения флаг не снимается, новый стрик с 0. Проблема только в описании награды 7-го (`GA-P20-014`).

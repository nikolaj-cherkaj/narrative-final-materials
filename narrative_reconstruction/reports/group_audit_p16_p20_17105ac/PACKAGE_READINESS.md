## P20 — `CONDITIONAL`

| Направление | Статус | Комментарий |
|---|---|---|
| Daily A-пути | `PASS` | D1 A, D2 A, D3 A проходят; DONE/CLEAR есть |
| Daily B/C-пути | `CONDITIONAL` | D1 C недостижим; D2 A/B/C пересекаются; D3 C пересекается с A/B |
| Weekly A-пути | `PASS` | W1 A, W2 A проходят |
| Weekly B/C-пути | `CONDITIONAL` | W2 B не сетаплен; W2 A/C пересекаются; W1 B/C корректны |
| Флаги | `PASS с OBS` | 12/12; `LIFELINE` вариант B; `TAMED` блокирует W1; но у daily/weekly A/B нет state-флагов |

| Скринридер | `PASS` | Тупот/хропіння/капання/гул; дымовой сигнал D1 — OBS |
| Язык | `PASS` | Без калек; «шаблі» и «ковальськими» исправлены |
| Новые MEDIUM | `GA-P20-012`…`015` | D1 C; D2 A/B/C; D3 C; W2 A/B/C |

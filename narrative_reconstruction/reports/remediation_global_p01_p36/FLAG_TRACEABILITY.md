## 1. `FLAG_P08_MAIN005_DONE` (фінал А/Б/В MAIN-005)

- Визначення: маркер завершення MAIN-005 і кампанії; блокує друге Серце/клинок/пакт (картка 446–453).
- Тип: one-shot. SET: P08:546 (А) / 559 (Б) / 571 (В). CLEAR: —.
- Умова SET: відповідний фінал; DONE не активний. Провал/відмова НЕ ставлять.
- CHECK: P08:469 (тригер), P08:546/559/571 (повтори); **нове — P23 GOD-11, тригер і умовна репліка 1101** (при DONE без станів — зима озера як місцевий залишок).
- Взаємовиключення: сам DONE ні з чим не конфліктує; стани нижче — між собою.

## 2. `FLAG_P08_PACT_KEEPER` (стан Хранителя, фінал Б)

- Визначення: Вічний Пакт Межі; брама запечатана на 1000 літ; щорічна варта, інакше печать слабне (картка 455–461).
- Тип: state. SET: P08:559 (складено зброю, Пакт з Мареною NPC-0413). CLEAR: —; ↔ `REBORN_SPRING`.
- CHECK: P08:559 (кінцівка: варта); **нове — P23 GOD-11: тригер 1075, репліка впізнання 1093, поновлення варти у Відлунні 1171**.
- Наслідок: Марена говорить як із вартовим межі; випробування кригою обов'язкове; ехо-пакт P23 — поновлення, не новий пакт; нагороди без змін.
- Невідповідність ДО: картка містила «майбутні межові сцени» без жодного зовнішнього споживача — тепер споживач є (P23 GOD-11). Усунено.

- `PAID_ARMOR`: маркер оплати обладунком (картка 236–243, виправлена: було «обладунком/грішми»). SET: P06:311 (Варіант 1) або P06:317 (**після правки — лише якщо фактично віддано обладунок**). CHECK: P01:1104 («ти віддав Саві обладунок»).
- `WORKED_OFF`: відробітка (картка 245–252). SET: P06:314/317. CHECK: P01:1106. Без змін.
- `PAID`: єдиний стан боргу (P01:578). SET: P06:311/314/317, P01:582/585. CHECK: P01:1102 (нейтральна «закрив борг» — покриває грошову оплату ранку після правки).

- Відома асиметрія (прийнята, не хибна): пряма здача обладунка Саві (P01:585) ставить лише `PAID` → нейтральна репліка (правда, менш специфічна). Змін не потребує; задокументовано тут.

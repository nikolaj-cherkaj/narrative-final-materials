## 4. Виправлення (тільки P23, P08/P09 не редаговано)

Тригер (P23:1075) доповнено пам'яттю: `PACT_KEEPER` → впізнання хранителя; `MARA_MARKED` → знак; `TRICKSTER` → підміна; `SHRINE_BURNED` → капище; `MAIN005_DONE` без станів → зима озера як місцевий залишок; `REBORN_SPRING` → останній лід межі.

Умовні TTS-репліки Марени в Акті I (порядок показу — за порядком у тексті, усі незалежні):
- P23:1093 (`PACT_KEEPER`): впізнання Вартового Межі; випробування зберігається («Та й хранителя я випробую»).
- P23:1095 (`MARA_MARKED`): впізнання тавра.
- P23:1097 (`TRICKSTER`): пам'ять про підміну.
- P23:1099 (`SHRINE_BURNED`): пам'ять про капище (без механіки).
- P23:1101 (`MAIN005_DONE` без `PACT_KEEPER`/`REBORN_SPRING`): залишок зими після розсічення Серця.

Відлуння (P23:1171): при активному `PACT_KEEPER` нового пакту не укладається — хранитель поновлює давнє слово; нагороди не змінено.

**Що свідомо НЕ зроблено:** статус Хранителя не дає пропуску випробування; нагороди/економіка не змінено; нових технічних ID — 0; P08/P09 не редаговано.

## 6. Побічні ефекти

- Відлуння P23 (`FLAG_P23_GOD11_PACT`) не конфліктує з `FLAG_P08_PACT_KEEPER`: різні ID, різні тексти; при KEEPER — явне розмежування (поновлення, не новий пакт).
- Схожі назви («Крижаний Саван Хранителя» P08 vs «Крижаний Саван Хранителя» фінал Б P23; «Хранитель Сезонного Кола» P23 vs «Хранитель Вічної Межі» P08) — різні предмети/титули, аудит не фіксував, не чіпано (поза межами GA-001/003).
- Повторний вхід (DONE) — без змін («лід пам'ятає кроки»).
- Пошук споживачів після правки: `PACT_KEEPER` → P08:559 (SET/повтор), P23 (CHECK); `REBORN_SPRING` → P08:571, P23; `MAIN005_DONE` → P08:469/546/559/571, P23; `MARA_MARKED`/`TRICKSTER`/`SHRINE_BURNED` → P09, P23. Зовнішніх конфліктів немає.

# ПИТАННЯ ВЛАСНИКУ — РЕМЕДІАЦІЯ GA-GLOBAL-001…008

**Статус: блокуючих питань — 0.** Усі 8 дефектів усунуто в межах чинного канону без нових сюжетних фактів.

---

## Необов'язкові уточнення (не блокують GO, відповідь — за бажанням)

1. **Пряма здача обладунка Саві (P01:585).** Ставить лише `FLAG_P01_SAVA_DEBT_PAID` → нейтральна репліка Гаврила «закрив борг» (правдива, але менш специфічна, ніж «віддав обладунок» для шляху P06). Залишити як є чи додати `FLAG_P06_DEBT_PAID_ARMOR` у P01:585 для симетрії? Поточне рішення: залишити (нейтральна репліка не бреше; ID з префіксом P06 у сцені P01 — небажаний прецедент).

2. **Схожі назви P08/P23.** «Крижаний Саван Хранителя» (обладунок P08 Б) vs «Крижаний Саван Хранителя» (фінал Б GOD-11, дає «Крижаний Панцир Марени»); «Хранитель Вічної Межі» (P08) vs «Хранитель Сезонного Кола» (GOD-11 А). Різні предмети/титули, плутанини в умовах немає. Залишити чи розвести назви? Поточне рішення: залишити (поза межами GA-001/003).

3. **Відлуння P23 «Пакт Північного Рубежу».** Для Хранителя P08 воно тепер трактується як поновлення давньої варти. Якщо власник хоче, щоб Хранитель узагалі не бачив третій шлях (лише 2 фінали), потрібне рішення про приховування гілки — це зміна структури квесту, тому не робилося. Поточне рішення: гілка доступна всім, сенс для Хранителя пояснено.

**Виконані роботи незалежно від цих питань:** усі 8 виправлень, 39 комбінацій, синхронізація реєстрів — завершено.

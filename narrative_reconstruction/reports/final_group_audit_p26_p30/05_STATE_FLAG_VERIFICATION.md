## 5. Особые проверки

### 5.1. P26 Q04/Q05

- Q04: после Б — «Берег пам'ятає герць», после В — «Редути пам'ятають будівничого» (P26:418). Универсальная фраза «Гора пам'ятає твій морок» осталась только для А.
- Q05: после Б — «Скелі пам'ятають власника бартки», после В — «Перевали пам'ятають печатника» (P26:520). Универсальная фраза «Скелі пам'ятають твою бартку» для В удалена.
- Оба флага имеют SET в своих финалах: P26:491, 496, 607, 615.

### 5.2. P29 `RUIN`

- SET только в финале Г: P29:288.
- Fail: P29:233 — «Провал флага не ставить, Сомка не страчують, `FLAG_P29_Q02_RUIN` не ставиться».
- Повтор после Г: P29:185 — «Руїну не переспівати!»; после fail флаг не активен, повтора памяти нет.
- Взаимоисключение с `RESCUE`/`SONG`: P29:269, 276, 288.

### 5.3. P28 Q02

- `DONE` — one-shot; повтор P28:158 перечисляет владельца рога.
- `BALM`/`WARD` — взаимоисключающие; SET P28:225, 230; CHECK P28:158, 225, 230.
- Финал А не имеет отдельного state дара (`GC-P28-Q02-VOICE-001` — OBS, future consumer).

## LOW

### GA2-P01-001 — омонимы-остатки (LOW)
- **Пакет/сцена/строки:** P01–P05 в целом; примеры: Михайло (коваль-прим.?/Сагайдак), Ярослав Залізняк (P04) vs Максим Залізняк (P26), Онисим (P04 SEA) / Онисько (P01 D-008), Хвесько/Фесько, Ярема (P03) / Ярема Жовтоводський (†1648, канон).
- **Воспроизводимый путь:** встретить обоих носителей имени в разных пакетах; короткого разведения в TTS-тексте нет (часть пар разведена: Грицько/Чорновух P02:797, Левко/Левко Сліпий P04:374/P05:533, Онисим/Микита, Ярослав/Максим — остальные без).
- **Влияние:** локальная путаница без влияния на прохождение (ID разные, квесты не ломаются).
- **Доказательство:** поиск по revised/ + отсутствие дисклеймеров в указанных сценах; INT-L-01 подтверждается частично незакрытым.
- **Предпочтительное решение:** при первом появлении в пакете — одна строка «не плутати з … (пак. N — інша особа)» (образец: P02:797, P04:127). Имена не менять. Риск: нулевой (только текст).
- **Связанные файлы:** P01–P05, `canon/CHARACTERS.md`.

### GA2-P01-002 — «Калинів» / «Калиновий» (LOW)
- **Строки:** P01:167/242/679/814 («Калинів Міст»), P08:87/93, P28:271 (варианты).
- **Путь:** пройти Z-007 (P01) → P08 MAIN-001 → P28; навигация называет объект по-разному.
- **Влияние:** навигационная шероховатость; звуковые ориентиры те же, путь не ломается.
- **Доказательство:** обе формы в текстах; INT-L-03 подтверждается.
- **Решение:** в заголовках/навигации — «Калинів Міст»; «Калиновий» — только художественная речь. Без изменения канона. Риск: нулевой.

### GA2-P01-003 — метрика части дистанций (LOW)
- **Строки (примеры):** P01:29 «сотні сажнів» (без эквивалента); остатки верст/сажнів без «десь … км/м» при первом употреблении в сцене.

- **Доказательство:** указанные строки; INT-L-07 частично остаётся.
- **Решение:** добавить «— десь …» в найденных местах, не убирая колорит. Риск: нулевой.

## OBSERVATION

### GA2-P05-001 — Тарас и Пугач (OBSERVATION)
- **Строки:** P01:87–89/387–389 (Тарас, горно + ковадло на пні), P02 R-001:29/35, P05:26/453 (ковадло Пугача в ніші за горном).
- **Суть:** после закрытия INT-M-02 оба кузнеца — в одном боковом гроте; кто кому кем приходится и почему два ковадла — не сказано.
- **Влияние:** не блокирует (ART-004 проходится), но игрок может спутать, к кому идти за легендарным крафтом.
- **Решение:** одна строка: «Тарас — молодший сварожич при горні, Пугач — старший хранитель Сварогового ковадла в ніші» (или утверждённая каноном версия). Механику не менять.

### GA2-P03-001 — Q-030В карма 0 (OBSERVATION)
- **Строки:** P03:592 (А −1000), P03:610 (Б −1000), P03:619–631 (В — без минуса кармы, но с розыском и изгнанием для члена Дружины P03:492–493).
- **Суть:** участие в вооружённом налёте в В прощено кармой («милосердие»), в А/Б — нет. Текст сам говорит «милосердя не скасовує розшуку».
- **Влияние:** моральная асимметрия; прохождение не ломает (баланс не оценивается).
- **Решение:** на усмотрение владельца: либо оставить 0 с явным лор-обоснованием («милосердие компенсирует»), либо −800 как «меньшее зло». Чисел не менять без балансировки.

## J. Нова структура CHARACTERS.md

`canon/CHARACTERS.md` v2.0 побудовано так:

1. **Правила ідентичності та іменування** — статуси, унікальність, фонетика, ID-блоки.
2. **Повний реєстр (383 записи)** — таблиця ID / ім'я / роль / регіон / перша поява / пакети / статус.
3. **Досьє персонажів** — для кожного запису: статус, стать, роль, регіон, локація, перша поява, пакети, квести, альтернативні імена, біографія/мотивація, зв'язки.
4. **Алфавітний покажчик** — ім'я → ID.
5. **Покажчик за пакетами** — P01–P36.
6. **Покажчик за регіонами**.
7. **Альтернативні імена та прізвиська** — таблиця.
8. **Конфлікти ідентичності та їх розв'язання** — стислий перелік.
9. **Історія перейменувань** — ID, старе ім'я, нове ім'я, пакети, причина.
10. **Правила для майбутніх сесій OpenCode**.

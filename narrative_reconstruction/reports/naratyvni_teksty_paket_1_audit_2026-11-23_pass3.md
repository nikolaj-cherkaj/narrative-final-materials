## F. Виявлені суперечності

1. **«20% щохвилини» vs §9 + TERMINOLOGY.** Усунуто нейтральним переписом + `TECH / БАЛАНС`.
2. **«відсоток» vs TERMINOLOGY §1.** Усунуто заміною на «наріст» (5 місць, 4 репліки).
3. **Тарас P01 vs P07, Радомир P01 vs P08, Ярослав vs Сокіл, Калинів Міст (пам'ять/монета), розв'язка Б D-014, безіменний оповідач → Свирид, пророцтво «на погодження», `(приклад)` у цінах, мета-посилання в TTS** — уже усунено в циклах 1–2, перевірено повторно, регресій немає.
4. **Могила безіменного кобзаря (Z-006) vs Левко Сліпий (P05) / Остап Кобзар (P25).** Не тотожні: P01 — безіменна могила з бандурою (лор-об'єкт, без квестів); P05 — привид-наставник на ярмарку; P25 — живий старий на Канівській горі. Об'єднання не потрібно; статус PROPOSED не надається.

## G. Мовна редактура

- «відсоток» → «наріст» (5 місць) — усунення модернізму/термінологічного порушення, збереження сухої манери Сави.
- «тане на 20% щохвилини» → «швидко висмоктує тепло й силу — кожен крок дається важче» — усунення числового immersion-брейку.
- Новий текст написано колоритною українською, без русизмів/калек; «подивись/побачиш» як єдині орієнтири — відсутні.
- TTS-чистота: службові дужки з реплік прибрані ще в циклі 2; `%` лишився лише в `TECH`-блоках.

## H. Невирішені проблеми (лише технічні / зовнішні, творчих немає)

1. **Баланс.** Робочі числа (20 срібняків відвар, 50 обоз, 10 червінців переправа, 6 кремінь, 12/8/40 товари Михайла, ефекти оберегів) — на затвердження геймдизайнеру. У тексті позначено `TECH / БАЛАНС`, проходження не блокують.
2. **Реєстр прапорців.** `FLAG_P01_*` мають setter/consumer у межах P01; потрібне внесення до глобального реєстру прапорців.
3. **Зовнішні теги.** P08 MAIN-004 (Z-005 vs фортеця), P07 «Драгобина/Драговина», P06 LORE-004 (скриня/корінь) — P01 робить сумісним, але самі P06/P07/P08 не змінювалися за §2.
4. **Чорна книга Навського Царя** — свідомий гачок, льох замкнено (D-006/D-011 узгоджено). Рішення автора: залишити гачком.
5. **Назва міста / точна карта** — P01 дає відносну географію; фінальна карта світу — окреме рішення.

Жодна з цих позицій не є білою плямою §14: художні відповіді «де / з ким / як / чому / що далі» є в сценарії.

## L. Результати симуляції проходження

Для кожного квесту — початкова точка → ключові етапи → перевірені варіанти → фінали → блокери → статус:

- **D-001 Вугілля:** кузня → смолярня (Микита живий, сліди → Яр) → заплатити / відібрати (блеф/бій/викуп) / спалити → нагорода / півціни + втрата довіри. Блокерів немає. **Прохідний.**
- **D-002 Серце Метеорита:** грот → кайло в Грицька → Курган (тон/три удари) → Серце → Горно P07 (3 фінали P07). Блокерів немає. **Прохідний.**
- **D-003 Відвар/Опівнічні трави:** лабораторія → купити / зібрати (чебрець+ладан+спирт) / відмовитися → лікування/прогресування; опівночі Z-009 третя ніша → купити/здати. **Прохідний.**
- **D-004 Відмички/Збут:** стіл Коржа → 50 зараз / 30+пакунок / зрив → повернення наступного дня (60/відмова/бій); збут з оцінкою → 3 продажі → Михайло. **Прохідний.**
- **D-005 Позика:** кантора → 100/50/відмова → 7 днів → повернення/нестача/запізнення/обладунок → колектор P06 / дефолт → Микола. **Прохідний.**
- **D-006 Покаяння:** храм → віск (ринок/борг) → хліб на Яворовий (засідка: бій/викуп/переконання/втрата) → могили (бій/налякати/викуп/розкидати) → молитва. Брехня виявляється. **Прохідний.**
- **D-007 Обоз:** двір → світанок біля брами (зброя) → байрак (вовки/татари: стріляти/палити/балка) → Січ → оплата. Втеча → холодність. **Прохідний.**
- **D-008 Риболовля/Протока:** причал → день (карась/невдача ×3) / ніч (ріж/тягни/кидай) → Онисько → `FLAG_P01_OLD_MILL_KNOWN` → Z-013 без ліхтаря. **Прохідний.**

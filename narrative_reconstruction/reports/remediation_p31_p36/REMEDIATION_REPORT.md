## 1. GA-P31-001 — финал Б HEARTH-31-01 (MEDIUM)

**Исходная проблема:** судьба хаты в финале Б не определена. Правило `P31:43` — без вуженя до заката хата сгорит. При этом `P31:76` подавал Б как альтернативу занесению вуженя, `P31:108` требовал только «Збишка поставлено на коліна», `P31:115` — «капище відбудовано» без упоминания хаты, `P31:116` ставил `SPOKUTA` без `LITOPYS`. Возможны несовместимые комбинации: Б без вуженя (хата должна сгореть) или Б после пожара без `LITOPYS`.

**Исходные фрагменты:**
- `P31:43`: «якщо … не посадити … молоде вуженя до заходу сонця — хата згорить…»
- `P31:76`: «занеси вуженя під поріг (фінал А), змусь Збишка … (фінал Б) або, якщо хата зайнялася, винеси … (фінал В)»
- `P31:108`: «Умова: Збишка поставлено на коліна.»
- `P31:115`: «Наслідок: Збишек на колінах — капище відбудовано; честь відновлено.»
- `P31:116`: `SET DONE + SPOKUTA`, `CLEAR: взаємовиключний з LITOPYS`

**Причина:** условие доступа к Б не включало обязательное условие спасения хаты, а последствие не фиксировало её судьбу. Флаги `SPOKUTA`/`LITOPYS` заявлены взаимоисключающими, но текст допускал Б в пост-пожарном состоянии.

**Выбранное исправление (Вариант 1 аудита):** Б возможен только после занесения вуженя (хата спасена). Пост-пожарный результат остаётся вариантом В с `LITOPYS`. `SPOKUTA` и `LITOPYS` одновременно не ставятся. Сохранён существующий сюжет (капище, конь громаде), новых механик нет.

**Точные места изменения (`naratyvni_teksty_paket_31.md`):**
- `P31:76` Розв’язка: «…занеси вуженя під поріг (фінал А); якщо вуженя вже під порогом і хата врятована — змусь Збишка … (фінал Б)…»
- `P31:108` Умова: «молоде вуженя під порогом до заходу сонця (хата врятована) і Збишка поставлено на коліна.»
- `P31:109` Дія: префикс «Вуженя вже під порогом — хата врятована.»
- `P31:115` Наслідок: «Хата врятована — вуж під порогом; Збишек на колінах — капище відбудовано; честь відновлено.»

**Итоговый фрагмент:** см. diff — 4 строки в Q01. Флаги не менялись по составу: Б = `DONE+SPOKUTA`, В = `DONE+LITOPYS`, взаимоисключение сохранено.

**Затронутые флаги:** `FLAG_P31_Q01_DONE`, `FLAG_P31_Q01_SPOKUTA`, `FLAG_P31_Q01_LITOPYS`. Реестр: уточнены призначення/SET `SPOKUTA` — «хата врятована (вуженя під порогом)».

**Повторная проверка:**
- Путь А: вуженя → хата спасена → `DONE`, повтор «Вуж-приймак п’є молоко!» — OK.
- Путь Б без вуженя: теперь невозможен по условию; текст Розв’язки прямо требует вуженя — OK.
- Путь Б с вуженем: хата спасена + покута → `DONE+SPOKUTA`, повтор «Каплиця стоїть…» — OK.
- Путь В: пожар → літописи → `DONE+LITOPYS`, повтор «Літописи дихають!» — OK.
- Комбинация `SPOKUTA+LITOPYS` недостижима — OK.

**Согласованность:**

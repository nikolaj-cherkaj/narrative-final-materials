# РЕАКЦИИ НА ПОСЛЕДСТВИЯ ВЫБОРА — ПРОВЕРКА

**Класс B:** 31 блок реакции на выбор/последствие, плюс связанные TECH-описания условий.  
**Стандарт:** `MEMORY_REACTION_STANDARD.md`.

## 1. Метод

Для каждого существенного B-блока установлено:

1. какое решение игрока вызывает реакцию;
2. соответствует ли текст этому решению;
3. не перепутаны ли положительная и отрицательная ветви;
4. не исчезло ли последствие;
5. не возникает ли реакция при неправильном условии;
6. не противоречит ли более позднему состоянию;
7. не дублирует ли другую реакцию без художественной причины;
8. сохраняется ли межпакетная зависимость.

Проверены все 31 B-блока и соседние CHECK/SET-строки. Флаги и условия не менялись (подтверждено пофайлово).

## 3. Положительные и отрицательные ветви

Проверены парные ветви:

- **P01 Сава:** PAID / PAID_ARMOR / WORKED_OFF / DEFAULTED — четыре разных отношения, не перепутаны. Условие PAID исключает ARMOR/WORKED_OFF.
- **P01 Брага:** ALLIED / TRIED / BRIBED — союз / суд / подкуп, разные реакции.
- **P02 Лісовик:** KILLED / иначе — враждебность / нейтральность.
- **P05 Чугайстер:** KILLED+ABSENT / KILLED без ABSENT / иначе — три состояния, прямые реплики.
- **P07 Водяник:** SOM_SOLD / SOM_FREED — враждебность / мир.
- **P14 мурза:** TYASMIN / DUEL / PEACE — три финала, разные последствия.
- **P18 Мамуна:** SWANS / ASHES / WARDENS — спасение душ / сожжение / стражи.
- **P24 Моровиця:** PACT / BURNED — долг сохраняется / мстит пепел.
- **P24 Мамуна:** MAMUNA_BANISHED / ODMINOK_HEALED — изгнание / домовой.
- **P31 Солониця:** HERO / SHADOW_RETREAT / LAST_STAND — слава / тень / терминальная смерть.

Ни одна ветвь не поменяла знак. Флаги и условия не изменены.

## 4. Межпакетные реакции

Проверены:

- **P01 D-015** → P03 (Брага), P05 (Чугайстер, упир), P06 (Сава, Літопис), P19 (Телесик), P22 (Семаргл), P31 (Солониця). Все условия сохранены, новые тексты не меняют факты.
- **P13/P05** → Чугайстер. P13 учитывает `_KILLED` и `_ABSENT`; новая общая строка повтора P13 Q03 («сидить і лузає горішки») может конфликтовать с враждебной ветвью, если показывается вместе с ней. Это O-02, не подтверждённый дефект.
- **P18/P24** → Мамуна. P24 использует P18 DONE/ASHES/SWANS/WARDENS; новый повтор Наталки соответствует этим состояниям.
- **P15/P28** → Цар-Вуж и рог. P28 сохраняет условие «рог у героя / у владики»; новые повторы не меняют.
- **P25/P26** → Устим Кармелюк. P26 CHECK `FLAG_P25_Q02_ALLIANCE` сохранён; новый повтор P26 Q01 не меняет союз.
- **P31–P36** → Солониця, Белый Остров, соль, козаки. Новые повторы не вводят новых фактов, кроме P26 Q01 (ґудзик) и P30 Q01 (сопилка).

## 5. Реакции, которые нужно исправить

1. **P26 Q01 (F-03, MEDIUM):** безусловный «ґудзик у нього в кишені» противоречит финалу А, где ґудзик может остаться у пана (строка 138).
2. **P13 Q03 TEAR (F-01, MEDIUM):** это не B-блок в классификации, но реакция на финал Б; крестик одновременно на дне и у Калины (строка 425).
3. **P30 Q01 A (F-02, MEDIUM):** повтор финала А противоречит награде (сопилка у игрока).
4. **P30 Q03 Б (F-04, LOW):** береговая варта vs подводная варта Семена.

## 6. Вывод

Реакции на последствия в целом сохранили смысл, условия и межпакетные связи. Подтверждённых перепутанных ветвей или потерянных последствий нет. Три MEDIUM-противоречия касаются конкретных предметов/локаций в повторах, а не логики флагов. После их исправления класс B можно считать принятым.

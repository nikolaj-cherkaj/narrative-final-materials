## 2. Соответствие условий и реакций

Проверены все группы:

- **Брага:** ALLIED → союз/бекеты; TRIED → суд/каторга; BRIBED → подкуп/слухи. Не перепутаны.
- **Телесик:** GOSLING → гусеня с героем; SAVED без GOSLING → «гусеняти при ньому не було». Корректно.
- **Семаргл:** HARVEST_SAVED → урожай спасён. Одна ветвь, без конфликта.
- **Казимир:** SPARED → живой, скарбница; EXECUTED → зарублен, пожар. Корректно.
- **Солониця:** HERO → слава; SHADOW_RETREAT → тень/молчание; LAST_STAND — терминальный, реакции в корчме нет. Корректно.
- **Михайло:** RUN_DONE → ночной чёлн. Одна ветвь.
- **Грицько:** DELIVERED → кузня работает; BURNED → смолярня сгорела, Микита у Олексы. Корректно.
- **Иларион:** SAVED → вернулся/молится; LOST → скит пуст. Корректно.
- **Панас:** ESCORT_DONE → доволен; FAILED → хмурый. Корректно.
- **Сава:** PAID (исключая ARMOR/WORKED_OFF) → доволен; ARMOR → отдал обладунок; WORKED_OFF → отработал мечом; DEFAULTED → угроза. Четыре разные реакции, не перепутаны.
- **Летопись:** все 5 + не rewarded → награда; все 5 + rewarded → повтор без денег; иначе → «старі сувої гуляють степами». Корректно.
- **Лісовик:** KILLED → лес осиротел; иначе → «стукає господар». Корректно.
- **Чугайстер:** KILLED+ABSENT → три ночи; KILLED без ABSENT → вернулся, помнит; иначе → танцует. Корректно.
- **Упир:** RESTED → дорога тиха; иначе → земля ворошится. Корректно.

## 3. Уникальность и конфликты

- Прямых дословных повторов активных реакций нет. Совпадающие мотивы (кухоль, чутка, «не хвались») несут разный смысл и разных адресатов.
- Внутри групп взаимоисключение соблюдено: Брага, Казимир, Телесик, Сава, Лісовик, Чугайстер, Упир, Солониця.
- Между группами возможны несколько активных реакций одновременно (Брага + Телесик + Сава + Лісовик и т. д.). Это не дефект: владелец подтвердил, что повторные диалоги нужны; вопрос порядка/ротации — ограничение формата.
- Новые правки P01: только 2 TECH-замены «пам'ять» → «стан» и 2 служебные связи (Остап, Летопись). Активные реплики Гаврила не переписаны.

## 4. Ротация

**Ограничение описано корректно.** В текстовом формате D-015 реакции заданы последовательными условиями:

```text
- Якщо активний FLAG_A: реплика A
- Якщо активний FLAG_B: реплика B
- Якщо активний FLAG_C: реплика C
```

Нет массива вариантов, поля `random`/`weight`, правила «выбрать одну из нескольких» или приоритета. Поэтому текущая логика действительно может быть последовательной или «первая подходящая» — это зависит от движка, а не от текста. Отчёт правильно фиксирует это как ограничение, а не как дефект переработки. Подготовленные варианты в разделе 6 отчёта в игру не добавлены.

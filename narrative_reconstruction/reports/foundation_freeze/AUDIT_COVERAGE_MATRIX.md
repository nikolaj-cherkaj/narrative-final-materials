## 3. Что именно не проверялось полностью

1. **Полная state machine для 181 сцены/энкаунтера.** Проверены завершённость, ветки, награды, провал, повтор и связи; не моделировались все комбинации кармы/репутации/флагов для каждой второстепенной сцены.
2. **Каждый из 385 NPC против каждого пакета.** Проверены 46 межпакетных и 12 ключевых; остальные — по реестру и упоминаниям.
3. **Баланс чисел.** Урон, проценты, цены, XP не проверялись на математический баланс; фиксировались только системные противоречия.
4. **Runtime-проверка.** Тексты не запускались в движке; выводы основаны на статическом анализе.
5. **Полная художественная редактура.** Язык проверен только на существенные дефекты (русизмы, терминология, порядок диалогов), не на стиль каждого абзаца.

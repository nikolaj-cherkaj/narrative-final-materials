## 3. Ключевые NPC: состояния и память

### 3.1. Лісовик (NPC-0427)

- **Первое появление:** P02 Q-010, живое дерево/дух леса.
- **Последующие:** P01 Z-002 (акустический маяк), P04 M-002 (Сіроманець/двойная данина), P02 эпилог (Олекса), P01 D-015 (слухи).
- **Смерть:** `FLAG_P02_LISOVYK_KILLED` — постоянная память; без боя не ставится.
- **Поведение:** лес теряет «тук-перетук», волки смелее, Олекса не даёт жетон/работу, Сіроманець требует двойную данину.
- **Оценка:** lifecycle согласован; последствия действительно меняют прохождение, а не только упоминаются. **OK.**

### 3.2. Чугайстер (NPC-0137)

- **Первое появление:** P05 BEST-001.

- **Смерть:** `FLAG_P05_CHUHAYSTER_KILLED` — постоянная; `_ABSENT` — временная (3 рассвета).
- **Память:** после респауна узнаёт игрока: «Ти вже вбивав мене»; повторная награда не даётся.
- **Оценка:** разделение двух флагов корректно; единственная неопределённость — SET при непровоцированном нападении (FF-MED-P05-CHUHAYSTER-001).

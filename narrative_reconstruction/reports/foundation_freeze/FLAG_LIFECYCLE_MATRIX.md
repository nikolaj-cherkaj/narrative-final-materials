**Проверенная версия:** `ac2b8de48a74186a1c43dca18882d0e080200366`  
**Метод:** regex `FLAG_[A-Z0-9_]+` по 36 пакетам; 56 уникальных токенов = 53 полноценных ID + 3 обрезанных стема (`FLAG_KAZYMIR_`, `FLAG_P01_SAVA_DEBT_`, `FLAG_Q021_`), которые не являются отдельными флагами и в реестр не входят.  
**Связанные отчёты:** `FOUNDATION_FREEZE_REPORT.md` (карточки проблем), `QUEST_DEPENDENCY_GRAPH.md`, `REGRESSION_FINDINGS.md`.

## 4. Проверка конфликтов SET/CLEAR

| Проверка | Результат |
|---|---|
| Флаг ставится, но никогда не проверяется | `FLAG_P04_CLASS_CHOSEN` — нет нарративного CHECK вне P04 (возможен боевой код) |
| Флаг проверяется, но нигде не ставится | Не найдено |
| Снимается раньше использования последствий | Не найдено для ключевых; `FLAG_P01_ILARION_PRAYER` не снимается после использования (не критично) |
| Временный флаг используется как постоянная память | `_ABSENT` и `_KILLED` разделены корректно; `_UPYR_RESTED` только окончательное упокоение |
| Постоянный флаг ошибочно сбрасывается | Не найдено для ключевых; долг `_DEFAULTED` сбрасывается новым займом — это спорно |
| Разные события используют один флаг с разным смыслом | Не найдено; `_KILLED`/`_ABSENT` разделены |

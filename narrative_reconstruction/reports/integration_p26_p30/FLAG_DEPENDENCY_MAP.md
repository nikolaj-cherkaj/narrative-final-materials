## 7. Флаги без потреби / неіснуючі CHECK
- Флагів без жодного CHECK у P26–P30 немає: кожен DONE читається тригером і/або повтором; кожен STATE — повтором.
- CHECK неіснуючих флагів немає: усі `FLAG_`-токени з текстів присутні в `FLAG_REGISTRY.md`.
- Нові ID не створювалися; `FLAG_REGISTRY.md` оновлено до v2.23.

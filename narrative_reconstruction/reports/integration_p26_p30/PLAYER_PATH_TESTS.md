## Сценарій D. Дослідник / альтернативні порядки

### D1. P26 і P27 у зворотному порядку
- P27 Q01 (Склик) → P26 Q02 (освячення ножів) на тому самому Дубі. Обидва епізоди не вимагають один одного; різні NPC (Мелетій/Мелхіседек). Результат: узгоджено, OBS щодо двох ігуменів.

### D2. P28 раніше за P15
- P28 Q02 без `FLAG_P15_Q03_DONE` → Цар-Вуж не впізнає, але дає ріг; `Q02_DONE`; дар отримано.
- Потім P15 Q03: P15 не має зворотного CHECK на P28, тому може вдруге дати дар. Це `GC-P28-P15-REVERSE-001` — OBS, не блокер P26–P30; у штатному порядку P15→P28 проблеми немає.

### D3. P28 після P15 з фіналом Б/відлуння
- P15 `GREED_PUNISHED` або `LIVING_WATER` → `DONE` активний, `NATURE_TONGUE` ні. P28 Q02: Вуж упізнає, але герой ще не має дару й приймає ріг уперше. Це виправлений HIGH.

### D4. Повторні входи
- P26 Q01 після DONE → Кармелюк «Башта пам'ятає твою крейду»; без нової втечі/нагород.
- P26 Q01-E після DONE → «Маєток пам'ятає вогонь»; без повторів.
- P27/P28/P29/P30 після DONE → лише пам'ять; DONE не ставиться повторно.
- P28 Q02 після провалу → повтор того ж дня; після DONE — пам'ять.

### D5. Відкладені квести
- P26 Q01-E можна відкласти: тригер вимагає `Q01_DONE`, не вимагає негайності.
- P29 Q02 одноразова; після DONE повтор — пам'ять.
- P30 квести незалежні; можна проходити в будь-якому порядку.

**Результат:** альтернативні порядки не ламають P26–P30; єдиний зовнішній OBS — P28→P15.

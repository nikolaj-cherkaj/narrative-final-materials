# АУДИТ ЖИЗНЕННЫХ ЦИКЛОВ ПРЕДМЕТОВ P01–P36

**База:** `c803155`.
**Метод:** для каждого сквозного предмета — происхождение → владелец → передача → потеря/возврат → использование в других пакетах → альтернативные состояния.
**Связанные документы:** `GLOBAL_FINDINGS_REGISTER.md`, `CROSS_PACKAGE_CONSISTENCY.md`.

## 3. Предметы, которые не отслеживались

Не отслеживались обычные расходники, еда, монеты, стрелы без сюжетного ID, ингредиенты и награды, которые не переходят между пакетами. Это соответствует условию аудита: не требовать отслеживания каждого расходного предмета.

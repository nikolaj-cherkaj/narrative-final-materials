# СКВОЗНАЯ СОГЛАСОВАННОСТЬ P01–P36

**База:** `c803155`. Проверялись фактические тексты 36 пакетов, а не только отчёты.
**Связанные документы:** `GLOBAL_FINDINGS_REGISTER.md`, `CHARACTER_LIFECYCLE_AUDIT.md`, `ITEM_LIFECYCLE_AUDIT.md`, `GLOBAL_DEPENDENCY_MAP.md`.

---

## 1. Метод

Для каждого значимого решения игрока прослежена цепочка:

`условие → SET флага/предмета → CHECK в следующем пакете → текстовая реакция → альтернативный маршрут`

Отдельно проверены:
- решения, которые объявлены «памятью мира» (P08 MAIN-005, P09 Q01, P15 Q02, P18 Q02, P22 Q03, P31 HIST-31-01);
- решения, которые меняют владельца предмета (P12 меч, P14 Плаха, P15 рог, P13 Бартка, P19 перла, P21 Соловейко, P28 рог, P34 Пектораль);
- решения, которые меняют статус персонажа (P05 Чугайстер, P08/09/23 Марена, P13/33 Арідник, P15/23 Недо́ля, P18/24 Мамуна, P25/26 Устим).

## 2. Ключевые цепочки и вердикты

### 2.1. P08 MAIN-005 → P23 GOD-11: Марена и Вечный Пакт

| Элемент | Содержание |
|---|---|
| Источник | P08 MAIN-005, финал Б (P08:550–559) |
| Решение | Герой заключает Пакт с Мареной, становится Хранителем Північного Рубежу; ставится `FLAG_P08_PACT_KEEPER` |
| Целевой пакет | P23 GOD-11 (P23:1060–1114) |
| Что проверяется | Только `FLAG_PAGAN22_HARVEST_SAVED` (P23:1070) |
| Ожидаемо | Марена узнаёт своего хранителя/пакт; при финалах A/C — учитывает изменение зимы |
| Фактически | Марена говорит с героем как с незнакомцем: «Ти тремтиш від холоду, смертний?» (P23:1081) |
| Вердикт | **FAIL — GA-GLOBAL-001 (HIGH)** |

**Почему это не «просто отсутствие упоминания».** P08:558 прямо говорит о ежегодной страже, P08:559 ставит постоянный флаг, `FLAG_REGISTRY.md:456–462` указывает «майбутні межові сцени» как CHECK. P23:1067 прямо заявляет, что это та же Марена, «чий подих чутно в P08 і P09». Это не необязательная отсылка, а обязательная согласованность характера и отношений.

**Альтернативные маршруты P08:**
- Финал А (`MAIN005_DONE` без state) — Серце Марени разрушено, зима на Шпиле отступает;
- Финал Б (`PACT_KEEPER`) — зима сохраняется, герой — хранитель;
- Финал В (`REBORN_SPRING`) — весеннее перерождение, зима сменяется весной.

P23 GOD-11 написан только под «зима активна» и не различает ни один из трёх исходов. Даже если считать P08-Марену локальным аватаром, личный Пакт (финал Б) должен быть узнан; это минимальный уровень исправления.

### 2.3. P15 Q02 → P23 GOD-07: запечатанная Недо́ля

| Элемент | Содержание |
|---|---|
| Источник | P15 QUEST-15-02, финал Б (P15:244–247) |
| Решение | Недо́ля запечатана в глечик и закопана на сто лет; ставится `FLAG_P15_Q02_NEDOLYA_SEALED` |
| Целевой пакет | P23 GOD-07 (P23:640–741) |
| Что проверяется | Ничего из P15 Q02 |
| Ожидаемо | При активном флаге Недо́ля отсутствует/запечатана; сцена работает с одной Долей или с эхом |
| Фактически | P23:652 перечисляет Недо́лю среди действующих лиц; P23:665 — она «тягне чорне сурове клоччя» |
| Вердикт | **FAIL — GA-GLOBAL-002 (HIGH)** |

**Почему предыдущее закрытие недостаточно.** Отчёт P21–P25 закрыл P15→P23 как «вони не переселені, а приходять на поклик Мокоші». Это отвечает на вопрос о месте жительства, но не о состоянии: запечатанная на сто лет Недо́ля не может прийти на поклик. Проверка `NEDOLYA_SEALED` отсутствует и в триггере, и в «Дійових особах», и в репликах.

### 2.4. P15 Q03 ↔ P28 FOLK-28-02: рог Царя-Вужа

| Элемент | Содержание |
|---|---|
| Источник | P15 QUEST-15-03 (P15:356–384) |
| Решение | Финал А — рог у героя; финал Б — у владики; эхо `LIVING_WATER` — герой возвращает рог |
| Целевой пакет | P28 FOLK-28-02 (P28:145–230) |
| Что проверяется | `DONE`, `NATURE_TONGUE`, `LIVING_WATER`, `GREED_PUNISHED` |
| Ожидаемо | Один рог; при `NATURE_TONGUE` герой возвращает рог; при остальных — владика скидывает его снова |
| Фактически | Всё реализовано; физического дубля нет |

**Обратный порядок.** Если P28 пройден раньше P15, P28 финал А без `NATURE_TONGUE` отдаёт рог герою, а P15 Q03 не проверяет P28 и может снова отдать/забрать тот же рог. P15 не редактировался; это открытый OBS, а не скрытый HIGH, потому что штатный порядок P15→P28 согласован.

## 3. Причинно-следственные разрывы, не связанные с P23

### 3.1. P06 CRAFT-002 → P01 D-015 (деньги/обладунок)

- P06:317 ставит `FLAG_P06_DEBT_PAID_ARMOR` при оплате «грішми/обладунком».
- P01:1104 при этом флаге говорит «ти віддав Саві обладунок».
- **Вердикт:** LOW, `GA-GLOBAL-006`. Основной маршрут долга (P01 D-005 → P06 CRAFT-002) не блокируется, но описание способа оплаты неверно для денежной ветки.

### 3.2. P26 HERO-26-01 → HERO-26-01-E (обещание)

- P26:118 называет эпилог «розв’язкою обіцянки», P26:168 — «слово дотримано».
- В HERO-26-01 (P26:18–58) нет обещания сжечь маєток.
- **Вердикт:** LOW, `GA-GLOBAL-007`. Причинно-следственная связь эпилога не обеспечена, но маршрут доступен.

### 3.3. P15 Q02 финал Б → P23 GOD-07 (Недо́ля)

- См. 2.3. Это не «отсутствие упоминания», а прямое противоречие состояния.
- **Вердикт:** HIGH, `GA-GLOBAL-002`.

## 5. Что не проверено и почему

- **Движок:** нет фактической реализации флагов, инвентаря, времени; проверялась текстовая логика.
- **Полный инвентарь:** предметы, не имеющие сквозного сюжетного значения, не отслеживались.
- **Числовой баланс:** награды/проценты — примеры; не проверялись.
- **Хронология:** игра допускает смешение эпох; проверялась внутренняя согласованность, а не историческая точность.
- **TTS/аудио:** исключены по условию.

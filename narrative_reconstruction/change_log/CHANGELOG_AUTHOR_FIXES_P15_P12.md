# CHANGELOG — правки за зауваженнями автора (P15 квест, P12 абзац)
Дата: 2026-11-12.

## P15 QUEST-15-01 «Срібна куля для Куця» (5 пунктів автора — усі закрито)
1. Механіка загадок: переписано Етап 3 — слухова механіка (репліка TTS → реакція-звук → вікно тиші), кожна загадка має чутний знак і дію гравця.
2. Провал: вказано тригер (різкий звук) і точку повернення (Етап 2, спорядження зберігається).
3. Фінали: додано *Умова* до A/B/В + кульмінаційна розвилка (а)/(б)/(в) у Етапі 3 — кожен фінал досяжний дією гравця.
4. Принада: джерела вказано (буркун — лука біля куреня; сіль — запас курінної церкви, видає Сірко) + лінк із Варіанту 3.
5. Тупики діалогу: Варіант 2 отримав редирект на план-загадки; Варіант 3 — лінк на Етап 1; Варіант 1 — лінк на Етапи 1–2.

## 8. Меры и TTS

### 8.1. Правило

- Метрика — основной стандарт; исторические меры — антураж с современным эквивалентом.
- В TTS единицы — словами; символы `%`, `м`, `кг`, `[TECH]`, `[0/X]` не озвучиваются.
- Проценты разрешены; слово «наріст» остаётся только для процента по займу.

## 11. Открытые вопросы и ограничения

1. Не все 28 пакетов без флагов получили новые флаги: по решению автора флаг добавляется только при наличии разумного потребителя или мирового состояния.
2. Не все исторические меры в сугубо художественных описаниях получили эквивалент: правило применялось к TTS и к величинам, важным для игрока.
3. Балансные значения не пересчитывались; числа-примеры остаются ориентирами для геймдизайнера.
4. Часть авторских анахронизмов и игровых терминов (например, «метеорит», «беруші», отдельные игровые роли) оставлена как стилистическое решение; явные лексические риски из аудита заменены.
5. Полная редактура всех 312 строк с историческими мерами не форсировалась, чтобы не перегружать текст повторяющимися пояснениями.
